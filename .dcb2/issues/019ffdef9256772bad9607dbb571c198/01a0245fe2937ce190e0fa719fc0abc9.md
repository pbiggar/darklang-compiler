# Trial result

Committed dedicated MIR loop preheaders that enable LICM for profitable reducible loops with non-simple entries.

## Evidence

## What changed

Added profitable preheader canonicalization before MIR LICM, including deterministic labels, outside-edge rewrites, SSA phi merging, and MIR tests for multiple entries, existing preheaders, and nested loops.

## How it works

LICM previously rejected loops with multiple outside predecessors or conditional entry edges. The retained transformation creates a preheader only for innermost natural loops with directly hoistable invariant work, avoiding unnecessary CFG growth; routine benchmarks did not exercise this CFG shape but the focused MIR proof shows the invariant operation moves out of the loop.

## Algorithm

1. Find reducible natural loops. 2. Skip loops with a usable simple preheader or no direct invariant candidate. 3. Create a deterministic preheader. 4. Redirect outside header edges to it. 5. Merge each affected header phi's outside inputs in a fresh preheader phi and replace them with one preheader source. 6. Run existing LICM, which hoists the invariant into the new preheader.
