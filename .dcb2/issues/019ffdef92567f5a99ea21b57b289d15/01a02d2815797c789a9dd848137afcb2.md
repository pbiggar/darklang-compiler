## What changed

Added an ANF optimizer regression test for a parameterized fixed-layout tuple; it asserts optimized ANF contains only the parameter add and no TupleAlloc or TupleGet bindings.

## How it works

Current main already contained the scalar-replacement transformation, so no projection-forwarding implementation change was safe or necessary. The retained test captures the focused positive result without relying on constant folding. The managed-field extension was not retained: TupleGet is borrowed during RC insertion, and the focused String case showed aggregate allocation and its RC lifetime are required. Residual risk is limited to untested aggregate shapes; managed ownership transfer remains intentionally unsupported.

## Algorithm

1. For a local TupleAlloc, track ownership-safe scalar elements. 2. Forward eligible TupleGet operations to their original atoms. 3. Let copy propagation and DCE remove aliases, projections, and an allocation with no remaining aggregate use. 4. Exclude managed fields so RC insertion retains the aggregate as the field owner.
