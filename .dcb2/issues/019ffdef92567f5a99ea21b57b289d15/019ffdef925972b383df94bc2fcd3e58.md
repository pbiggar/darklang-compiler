# Scalar-replace local aggregates

Eliminate non-escaping tuple and record allocations whose fields can remain as SSA values.

## Constraints

- Restrict the first trial to fixed-layout aggregates with complete local escape information; preserve allocation for identity-sensitive raw operations, unknown calls, storage, or returns.
- Model managed-field ownership explicitly and add failing ANF/MIR tests before changing projection forwarding; run full verification and routine benchmarks.
- Retain only cases with material allocation or instruction savings; document the result and remove temporary benchmark programs.

## Trial work

### Trial item 019ffdef925673b6b91180d1e81228d6

Title: Scalarize non-escaping scalar aggregates

Category: scalar replacement of aggregates

Evidence: Records and tuples lower through TupleAlloc/TupleGet, while 2.3_ANF_Optimize.fs only forwards individual ownership-safe local projections.

Outcome:

Forward all scalar fields and delete the aggregate allocation and loads.

### Trial item 019ffdef9256758faa7d5f19552bd796

Title: Trial ownership-safe managed fields

Category: ownership-aware escape analysis

Evidence: The existing optimizer deliberately blocks managed projection forwarding because borrowed-field lifetime information would otherwise be lost.

Outcome:

Extend scalar replacement only where reference-count insertion can preserve every managed field lifetime.
