# Design brief

## Problem

At compiler b2e1f3d1e4ce0338d4c4662db9a1326f2e2cb899 versus darklang/dark 04fbe9dcc995c6188757d583e273cbd30a3e2d3d, recursive availability is flattened rather than represented with Dark’s scope-sensitive self and dependency-group semantics, causing differences in syntax, shadowing, cycles, and polymorphism.

## Goals

- Match canonical `let` declaration syntax without `rec` or `and` modifiers
- Match self-recursive functions and lambda-bound values, package-level mutual groups, local scope boundaries, and shadowing
- Carry resolved group and member identities explicitly through typing and lowering
- Document AOT annotation and polymorphism restrictions as intentional divergences

## Proposed solution

Have resolution construct explicit dependency groups from canonical declarations and lexical bindings. Named local functions and directly lambda-bound values receive interpreter-compatible singleton self groups; package-level declarations form mutual groups from resolved dependency cycles; ordinary value right-hand sides remain non-recursive, and local forward references remain unavailable. Carry stable binder, group, and boundary identities into typing and lowering. Check each recursive group together, generalize only after the group, permit productive recursive data and delayed function cycles, and reject eager value cycles, alias-only cycles, and type-changing polymorphic recursion with structured errors. Accept the interpreter’s annotation forms and omission points while retaining documented static rejection for inconsistent or underdetermined programs. Treat blanket mutual visibility and legacy `def` declarations as compiler-only extensions to remove after migrating affected sources. Preserve tail-call behavior only where required for valid baseline programs to complete observably.

## Success criteria

- Canonical self-recursive declarations and recursive lambda-bound values produce interpreter-equivalent results
- Package-level mutual and cross-group references resolve independently of source order, while unsupported local forward or mutual references fail equivalently
- Lexical shadowing, rebinding, annotations, and qualified references select the same observable binding, subject only to documented static typing differences
- Invalid value, type-alias, and polymorphic cycles terminate compilation with deterministic diagnostics rather than hanging, using sentinels, or failing during lowering
- Valid same-source recursive programs that complete at the pinned interpreter revision also complete with equivalent results
