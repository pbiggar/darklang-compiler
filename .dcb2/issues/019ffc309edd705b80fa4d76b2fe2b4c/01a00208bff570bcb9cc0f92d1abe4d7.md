## Work item 01a00208bff57bfaa3c1d63a5265316d

## Work item 01a00208bff57399a198372f67de2652

Title: Match local recursive scope and shadowing

Category: behavior

Evidence: Interpreter ProgramTypesToRuntimeTypes.fs:450-568 and 705-730 implements these distinctions: parameter and outer-binding shadowing suppress self recursion, package-name collision is rejected, later nested calls are rejected, and ordinary RHS evaluation precedes binding. nested-fns.dark:40-76 exercises each case.

Outcome:

Give a named local lambda singleton self availability only when its body resolves to that new binder. Parameters and existing outer lexical binders must win where the interpreter treats the occurrence as capture or shadowing; a same-name visible package function must produce the baseline ambiguity, later local functions must remain unavailable, and earlier local functions must be captured normally.

## Work item 01a00208bff57f57af757ea79a61f8ea

Title: Type recursive groups monomorphically

Category: function

Evidence: Pinned TypeChecking.fs:4982-5057 checks each function independently against predeclared signatures, while 5217-5294 exposes every function through one global environment. Let checking at 2175-2191 correctly excludes ordinary RHSs but has no recursive-lambda case or group-level generalization.

Outcome:

Allocate one monomorphic assumption per recursive member, constrain it with any source annotations, check all member bodies against the shared assumptions, solve the complete group, and generalize only the completed group. Instantiate references to already completed or imported groups normally, while preserving AOT diagnostics for genuinely underdetermined declarations.

## Work item 01a00208bff572cbbbacb89573cab68f

Title: Reject invalid recursive type and value cycles

Category: behavior

Evidence: Interpreter ProgramTypesToRuntimeTypes.fs:705-730 grants self availability only to named lambda RHSs and evaluates other values before binding. Compiler AST and declaration summaries admit aliases and values without a visiting-state or recursive-edge model; the accepted scope also requires invalid cycles to fail consistently.

Outcome:

Classify dependency edges explicitly as delayed callable references, eager value dependencies, or type-alias dependencies. Permit function and directly lambda-bound value cycles, reject eager value SCCs deterministically, reject alias-only type cycles while retaining nominal recursive ADTs, and ensure every cycle terminates in a structured diagnostic rather than resolver, type-expansion, or specialization nontermination.

## Work item 01a00208bff57172b47f92ee92d60c81

Title: Enforce the polymorphic recursion boundary

Category: behavior

Evidence: Pinned TypeChecking.fs:5317 onward discovers explicit specializations after individual function checks. AST_to_ANF.fs:2844 onward repeatedly creates concrete TypeApp specializations, but neither stage represents recursive-group assumptions, leaving type-changing recursion liable to late failure or an expanding specialization worklist.

Outcome:

Prevent recursive references from receiving fresh instantiations inside their own group, reject type-changing self or mutual calls with a dedicated polymorphic-recursion error, and allow ordinary let-generalized or completed-group functions to be used at multiple types outside the group. Feed only validated concrete specializations to monomorphization.

## Work item 01a00208bff57d088bb6146bb98d1f13

Title: Lower recursive closures from identities

Category: function

Evidence: Pinned AST_to_ANF.fs:2617-2686 builds global string-keyed function registries; 2734-2782 recognizes function values by textual membership without removing shadowed names; 2793-2842 rewrites wrappers by string. This can conflate a lexical binder with a same-spelled function and carries no group boundary into ANF.

Outcome:

Lower each recursive group using its member identities and a fixed group-environment layout containing outer captures and member code references. Direct calls, function values, wrappers, lifted lambdas, and reconstructed recursive closures must select members by identity, preserve lexical capture, and avoid creating an uncollectable cycle of ordinary closure values.
