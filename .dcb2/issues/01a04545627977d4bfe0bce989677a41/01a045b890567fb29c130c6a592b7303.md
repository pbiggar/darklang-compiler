# Trial result

Balanced dispatch reduced eight-way constructor-match depth from 7 to 3 and tag loads from 7 to 1, but runtime was statistically neutral and binary size regressed by 8 bytes, so the clean checkpoint is retained as optional. No established-suite improvement was proven; overall multiplier: 1×.

## Evidence

## Problems

Replace linear constructor-tag test chains with a semantics-preserving balanced dispatch tree when it reduces generated branches.

## Solution

The retained candidate replaces eligible source-ordered equality chains with balanced <= comparisons. Unique exhaustive tags make source order unobservable, while compiling payload extraction and bindings only in the selected leaf preserves evaluation order, nested-pattern behavior, and reference counts. Managed-string payload coverage passed through the native leak-checked E2E path. The deterministic structural result improved substantially, but the focused runtime measurement was indistinguishable within noise and the emitted binary grew from 688 to 696 bytes. Residual risk is concentrated in code-size and branch-prediction tradeoffs across real constructor distributions; therefore this is reported as no-improvement despite the retained structural checkpoint.

## Implementation

- Recognizes exhaustive matches of at least four unique, unguarded constructor cases with irrefutable payload patterns.
- Sorts scalar constructor tags and builds a median-split threshold tree.
- Hoists boxed-sum tag extraction outside the dispatch tree.
- Leaves guarded, overlapping, grouped, nested-rejecting, and non-exhaustive lowering unchanged.
- Adds deterministic ANF-shape coverage and five end-to-end behavior cases.

### Algorithm

1. Require at least four cases and prove exhaustive constructor coverage.
2. Require one unguarded pattern per case, an irrefutable payload pattern, and distinct scalar tags.
3. Sort cases by canonical runtime tag.
4. For boxed sums, load the tag once; for pure enums, use the scalar scrutinee directly.
5. Split the sorted cases at the midpoint.
6. Emit tag <= maximum-left-tag and recursively lower both halves.
7. At each leaf, run the existing body and payload-binding lowering.
8. Route every ineligible match through the existing sequential chain.

### Example

Before, `match value with A(n) -> n | B -> 2 | ... | H -> 8` emitted repeated `load tag; tag == A; else load tag; tag == B; ...`, reaching H after seven comparisons. Afterward it loads the tag once and tests `tag <= D`, then `tag <= F`, then `tag <= G`, reaching H after three comparisons. Payload extraction for A remains inside A's leaf, demonstrating that dispatch changes without eagerly evaluating bindings.
