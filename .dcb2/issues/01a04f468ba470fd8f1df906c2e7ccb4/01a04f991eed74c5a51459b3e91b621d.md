## Conversation response

Repository research confirms the current quick suite is implemented as duplicated source: all 23 problems have both `dark/quick.dark` and `rust/quick.rs`, with separate quick expected-output files. The routine harness runs binaries with no positional argument, and the diagnostic Go/Node/Python/F#/OCaml implementations likewise hard-code their full workload. Dark has CLI environment support but no public argv primitive, so this refactor must first expose command-line arguments in the compiled language.

Refactor the benchmark contract so one source per implementation accepts a required positional workload parameter. Profiles provide the full and quick argument vectors; every runner passes them for output checks and measurement. This makes full and quick executions the identical executable/source path under different inputs, including the TinyTemplate Cargo driver.
