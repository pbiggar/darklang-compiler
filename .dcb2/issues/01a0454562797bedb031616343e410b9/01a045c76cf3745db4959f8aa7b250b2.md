# Trial result

Retained the clean candidate because runtime work improved 9.86%, but classified the trial no-improvement due to a conflicting 80% median specialization-pass timing regression. No established-suite improvement was proven; overall multiplier: 1×.

## Evidence

## Problems

Specialize profitable direct call sites with non-uniform literal arguments without globally rewriting every caller.

## Solution

After uniform parameter propagation, the pass finds larger helpers that survived inlining and have two or three observed integer/boolean literals at one foldable parameter. It creates literal-substituted clones and retargets only matching direct calls. MIR folding then removes constant control flow. Whole-program call-graph analysis rejects recursive cycles and escaping references; strict clone and node limits bound code growth. Runtime evidence improved substantially, but the specialization pass itself became measurably slower on the focused input, so the checkpoint is retained as an optional candidate and reported as no-improvement.

## Implementation

- Added bounded integer/boolean literal cloning for large, internal, nonrecursive direct callees.
- Preserved normal, borrowed, and tail-call conventions while retaining originals for unmatched callers.
- Capped specialization at three variants per function, eight per program, 192 cloned nodes, and 64 nodes per callee.
- Excluded recursion, function references, closures, strings, floats, managed values, and indirect uses.
- Added focused ANF exclusion/bounds tests and an end-to-end regression fixture.
- Documented the optimization and measured tradeoffs in `docs/classic-optimizations.md`.

### Algorithm

1. Run existing uniform direct-parameter propagation.
2. Reanalyze remaining direct calls, escaping references, function sizes, and the direct-call graph.
3. Reject callees participating in recursive cycles, used as function references or closure targets, outside the size limits, or lacking a foldable parameter use.
4. Select the first parameter having two or three distinct integer/boolean literals.
5. Enforce per-function and program-wide clone/node budgets.
6. Clone the callee once per selected literal, remove that parameter, and substitute the literal in its body.
7. Retarget matching normal, borrowed, and tail calls without changing their convention.
8. Retain the original when any direct caller is unmatched; otherwise remove it.
9. Allow downstream MIR folding and LIR lowering to eliminate constant branches.

### Example

Before, `choose(mode, value)` was called as `choose(1, n)` and `choose(2, n)`. ANF retained one two-parameter function; allocated LIR performed `Cmp(mode, 1)` and a conditional branch on every call. After specialization, calls target `choose$literal_0_1(n)` and `choose$literal_0_0(n)`. The original disappears because all calls were covered, and both generated clone bodies contain zero mode comparisons or conditional branches. This directly demonstrates local specialization of distinct literals without changing nonliteral callers.
