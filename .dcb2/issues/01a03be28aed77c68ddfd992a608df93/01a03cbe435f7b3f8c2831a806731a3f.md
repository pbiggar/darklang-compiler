## Algorithm

1. Match only scalar HeapLoad/HeapStore operations with the exact SSA address, offset, and type in one basic block.
2. Forward an immediately following matching load from a scalar store.
3. Reuse a prior matching scalar load only through scalar-transparent instructions.
4. Clear availability at stores, calls, allocations, runtime/memory instructions, ownership-sensitive operations, and block boundaries.
5. Lower forwarded loads as moves.
