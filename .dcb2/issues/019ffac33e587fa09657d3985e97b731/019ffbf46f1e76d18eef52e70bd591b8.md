# Design brief

## Problem

At compiler HEAD 51093e0a8e31fe45a9aa79a317fbefd6b74fbcc3, streams are absent; darklang/dark revision 04fbe9dcc995c6188757d583e273cbd30a3e2d3d defines the parity baseline. The gap covers lazy consumption, state ownership, error propagation, aggregation, composition, and deterministic resource disposal. DCB1 report 8a402797 is historical evidence only.

## Goals

- Match the interpreter’s observable stream behavior at the recorded revisions
- Preserve laziness, ordering, and single-consumer state
- Guarantee deterministic, one-time disposal across completion, early termination, explicit closure, and callback failure
- Classify every compiler-only extension and intentional divergence explicitly

## Proposed solution

Add an opaque lazy stream abstraction with explicit lifecycle and resource ownership. Construction and transformation remain demand-driven; consumption advances shared single-consumer state; composition transfers or cascades ownership; terminal consumption, exhaustion, early termination, explicit closure, and failures deterministically release owned resources. Interpreter behavior remains authoritative, with any stronger lifecycle guarantee recorded as an intentional divergence rather than silently treated as parity.

## Success criteria

- Equivalent programs produce the same values, ordering, demand-driven callback behavior, and public errors at the recorded revisions
- Repeated consumption observes one advancing stream rather than independent replay
- Owned resources close exactly once at the defined lifecycle boundary, including nested composition and failure paths
- Post-exhaustion and post-close behavior is deterministic, with no undeclared extensions or divergences

## Open questions

- Must the initial delivery include a concrete external-resource producer, or only the resource-capable stream model within the scoped surface?
- Where deterministic disposal would strengthen an interpreter edge case, should that be an intentional divergence or deferred until the interpreter contract changes?
