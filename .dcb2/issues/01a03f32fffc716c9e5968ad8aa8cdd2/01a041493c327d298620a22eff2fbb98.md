## Implementation

- Candidate repairs scalar HeapStore replacement direction.
- Removes only earlier same-block matching scalar stores.
- Preserves later stores and blocks elimination across observable or managed operations.

### Algorithm

1. Track scalar HeapStore locations by SSA address and offset within each block.
2. When a later barrier-free matching store appears, remove the earlier store.
3. Retain the later store.
4. Clear tracking at reads, calls, allocation, raw memory, reference counting, control flow, and other barriers.
5. Exclude managed and non-scalar stores.

### Example

Before: HeapStore(addr, 0, 1); HeapStore(addr, 0, 2). After: HeapStore(addr, 0, 2). The later value remains authoritative while the overwritten scalar write is removed.
