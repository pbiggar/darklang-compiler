# Devirtualize non-escaping closures

Turn known local closure calls into direct calls and remove avoidable closure allocation.

## Constraints

- Preserve capture evaluation order and reference-count ownership; retain allocation whenever the closure escapes, is stored, returned, or reaches an unknown call.
- Add failing ANF/MIR and generated-code tests first for capture-free, captured, escaping, and reused closures; run full verification and routine benchmarks.
- Measure quicksort and other higher-order workloads separately; retain only justified variants, update the backlog, and remove temporary inputs.
