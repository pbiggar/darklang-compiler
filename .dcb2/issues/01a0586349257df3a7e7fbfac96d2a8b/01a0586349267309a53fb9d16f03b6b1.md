# Bring compiler closer to interpreter, RE Builtin modules

The compiler and the interpreter are still quite different. We wish to bring them closer and closer together over time.

At the moment, one issues is that the upstream interpreter has a lot of builtins referenced from packages/ in its repo. We would like to at some point adopt all these packages, including things like File IO, System things, etc. These packages directly call functions with the format `Builtins.[functionName]`.

We want to start to implement some of these builtins, using compiler intrinsics, syscalls, or other ways as necesary. First, we will need to plan how that's going to happen. Audit all of the interpreter's builtins, putting them into categories, and include the full list of Builtins and the Mdoules or functions which call them (as appropriate).
