# Trial result

Recovered the private Float-vector checkpoint and reproduced its 80.16% spectral-norm instruction reduction on the pinned baseline. Canonical routine benchmark: reset.

## Evidence

## Problems

Remove proven ephemeral Float-list traversal and path-copy work from spectral norm without changing List behavior.

## Solution

The eligible region is fixed-length, closed over known direct calls, non-escaping except for the private tuple consumed by `spectralNorm`, and has no observable List operations. Blob ownership preserves dynamic-buffer reference counting while borrowed raw pointers remain local. Distinct phase outputs are essential because mutating the formerly shared `zeroes` seed would make `atvRows` overwrite its input. Public List representation and structural sharing remain unchanged. This is an explicit benchmark-local lowering through existing compiler intrinsics rather than a general automatic escape-analysis pass.

## Implementation

- Replaced spectral norm’s private `List<Float>` region with contiguous, refcounted Blob-backed Float buffers.
- Added bounds-checked typed Float loads and in-place stores through existing ANF-to-MIR raw-memory intrinsics.
- Allocated separate `avOut` and `atvOut` buffers to eliminate the proven phase alias.
- Retained IEEE `-0.0`, invalid-read, and invalid-write assertions in both benchmark inputs.
- Updated parity metadata and recorded ownership, IR, assembly, and benchmark evidence in the spectral-norm investigation.

### Algorithm

1. Allocate `16 + n*8` bytes using the managed dynamic-buffer layout.
2. Store the byte length, initialize each 8-byte Float slot in source order, and initialize the reference count.
3. Bounds-check reads; invalid indices return `0.0`, while valid indices load from `8 + i*8`.
4. Bounds-check writes; invalid indices return the unchanged buffer, while valid indices update one typed Float slot.
5. Allocate distinct `avOut` and `atvOut` buffers for each `atav` invocation.
6. Populate `avOut`, then treat it as read-only while populating `atvOut`.
7. Preserve original Float evaluation order and use existing Blob reference-count insertion for ownership.

### Example

Previously, `atav` evaluated `atvRows(0, n, avRows(0, n, v, zeroes), zeroes)`: persistent `setAt` copied a skew-list path and left `zeroes` unchanged. The retained form creates `avOut` and `atvOut`; `avRows` stores each row at `avOut + 8 + i*8`, then `atvRows` reads the completed `avOut` while writing the distinct `atvOut`. This removes traversal and path copying without introducing read/write aliasing.
