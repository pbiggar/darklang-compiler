# Trial result

Rebased and refreshed candidate still removes nqueen’s recursive caller saves, improves nqueen instructions by 6.233%, and passes all correctness and routine-performance checks without integration.

## Evidence

## What changed

Caller-save liveness is captured at the matching RestoreRegs boundary instead of before argument setup. ARM64 separately retains only registers required to back genuine argument parallel-move conflicts. Added allocation-level tests for dead argument exclusion and argument-cycle preservation. Refreshed the ARM64 routine snapshot, results, and history, and corrected stale fannkuch parity hashes already present on the target without changing benchmark sources or workloads.

## How it works

The allocator treated argument-only values as live across calls because SaveRegs was before ArgMoves. In nqueenSolve this caused X1/X2 stores, loads, and stack adjustments on every non-base recursive call even though the continuation only uses the returned value and X26 accumulator. The rejected stack-reservation-only experiment was not retried because it leaves executed memory operations intact. Restore-boundary liveness was chosen because it precisely models values that must survive the call, while explicit ARM64 ArgMoves backing preserves ABI and parallel-move correctness. Complexity remains linear in block instructions and argument moves. Residual risk is limited to unusual malformed SaveRegs/RestoreRegs sequences, which deliberately crash rather than assume pairing; the full suite and dedicated cycle test cover normal lowering.

## Algorithm

1. Walk each block backward and pair empty RestoreRegs with its preceding empty SaveRegs. 2. Snapshot integer and floating-point continuation liveness at RestoreRegs. 3. Scan ARM64 ArgMoves for non-self caller-saved sources that are also destinations and therefore need saved backing. 4. Union continuation-live registers with required move-backing registers. 5. Populate identical SaveRegs and RestoreRegs operands. 6. Emit no stack or memory operations when both sets are empty.
