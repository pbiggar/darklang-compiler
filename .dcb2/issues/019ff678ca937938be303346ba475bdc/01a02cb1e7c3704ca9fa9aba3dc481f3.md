## Algorithm

1. Validate a function’s parameter register-bank counts. 2. Fold parameters for initial maximum VReg. 3. Fold blocks and instructions in map/list order. 4. Validate each call’s register-bank counts while updating the maximum VReg. 5. Scan each terminator. 6. Construct TempState from the resulting integer and float maxima, or return the first deterministic limit error.
