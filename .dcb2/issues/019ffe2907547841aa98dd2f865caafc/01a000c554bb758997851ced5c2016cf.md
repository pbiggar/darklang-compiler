# Implementation plan

Both suites contain complete snapshots, but neither enforces the accepted monotonic suite policy: quick gates individual rows and can save partial results, while routine verification requires equality and recording overwrites stronger results. HISTORY.md shows the current 2cc404d0 routine snapshot is approximately 0.392% worse geometrically than the complete c97f99a1 run. The revised scope makes each baseline the best-known compatible complete run: improvements replace it automatically, regressions cannot replace it, contract changes fail closed, and repository integration cannot leave a discovered improvement unrecorded. An older compiler attribution is therefore valid when that run remains stronger, not evidence of staleness.
