## Algorithm

1. Find reducible natural loops.
2. Require one preheader, one scalar return exit, and a bounded pure scalar body.
3. Identify an internal branch controlled by a Bool header phi.
4. Prove every backedge copies that Boolean unchanged.
5. Clone the loop and scalar exit.
6. Replace each repeated invariant branch with its selected jump.
7. Dispatch once from the preheader to the true or false loop variant.
