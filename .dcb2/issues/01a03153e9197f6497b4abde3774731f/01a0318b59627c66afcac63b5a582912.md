## How it works

The representative recursive loop carried an input Bool through a header phi but branched on it every iteration. The retained transform recognizes only a unique-preheader, one-exit, bounded pure scalar natural loop where each Bool-phi backedge source resolves through scalar copies to that phi. It routes the preheader to the original true-specialized loop or a cloned false-specialized loop, replacing the repeated condition branch with jumps. The scalar return exit is cloned to prevent cross-variant phi/return corruption. The principal residual risk is intentionally addressed by narrow eligibility: loops with effects, ownership, memory, calls, multiple exits, or non-scalar state do not transform.

## Algorithm

1. Find reducible natural loops.
2. Require exactly one jumping preheader and one direct scalar return exit.
3. Require a bounded pure-scalar loop body.
4. Find one internal branch controlled by a Bool header phi.
5. Prove every backedge source resolves through scalar copies to that same phi.
6. Clone loop blocks and the scalar exit with fresh labels/registers.
7. Replace the original internal branch with its true jump and cloned branch with its false jump.
8. Replace the preheader jump with one branch selecting the specialized variant.
