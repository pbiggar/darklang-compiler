# Implementation plan

Pisum’s published Dark baseline is 95,305 instructions, but direct Cachegrind measurement of the executable for the parity-locked workload is 55,014,671 instructions. The Rust baseline is 50,258,602, so the valid comparison is roughly 1.10× Dark/Rust. The recorded result must be replaced only after identifying and preventing the artifact/provenance failure that admitted it.
