# Implementation plan

Pisum’s 95,305-instruction record is invalid; the audited workload measures about 55,014,671 Dark instructions versus Rust’s 50,258,602. The benchmark pipeline validates source parity but does not bind the measured executable to the fresh build that produced it.

## Work item 01a026b2869e7db6a68b86d52ba33715

Title: Bind benchmark measurements to freshly built artifacts

Category: behavior

Evidence: The runner builds into reusable problem-local executable paths, while Cachegrind later measures only those paths and result records contain no artifact identity.

Outcome:

Build each measured implementation into run-scoped artifacts and record verifiable provenance linking the audited source, compiler identity, and executable digest; reject a measurement when that linkage is missing or mismatched.

Title: Replace the invalid Pisum routine record

Category: other

Evidence: The canonical ARM64 snapshot and rendered results publish 95,305 instructions despite the valid direct measurement being 55,014,671.

Outcome:

Regenerate the canonical routine snapshot, rendered results, and history from a complete provenance-validated run so Pisum reports its valid runtime count and no false Dark advantage remains.
