## Work item 01a000d488fe773197db60fb76940e45

Title: Replace the Bytes runtime type with Blob

Category: type

Evidence: C@51093e0: src/DarkCompiler/AST.fs:41, Stdlib.fs:144-148, ANF.fs, MIR.fs, LIR.fs, Runtime.fs, both code generators, and parser/type-checker cases all model TBytes; [I RuntimeTypes.fs](https://github.com/darklang/dark/blob/04fbe9dcc995c6188757d583e273cbd30a3e2d3d/backend/src/LibExecution/RuntimeTypes.fs#L672-L716) defines distinct TBlob/DBlob identity.

Outcome:

Introduce Blob as the only binary type in the AST, both parsers, type checker, pretty-printer, ANF/MIR/LIR ownership shapes, refcount insertion, runtime helpers, and ARM64/x64 backends. Rename binary conversion, printing, and refcount operations to Blob terminology while retaining the managed length/data/padding/refcount layout. Remove every TBytes, DynamicBytes, and Bytes-named runtime operation; Bytes remains only a stdlib extension namespace whose functions accept and return Blob.

## Work item 01a000d488fe707889cc101666261686

Title: Add the canonical Blob.empty value and Blob identity behavior

Category: behavior

Evidence: The compiler module registry currently contains functions only and TypeChecking.fs:1240 rejects TBytes equality. [I Blob.empty](https://github.com/darklang/dark/blob/04fbe9dcc995c6188757d583e273cbd30a3e2d3d/packages/darklang/stdlib/blob.dark#L9-L10) is a value; [I equality](https://github.com/darklang/dark/blob/04fbe9dcc995c6188757d583e273cbd30a3e2d3d/backend/src/Builtins/Builtins.Pure/Libs/NoModule.fs#L119-L126) compares Blob handles, and backend/tests/Tests/Blob.Tests.fs:525-577 covers the observable cases.

Outcome:

Add typed stdlib-value registration and name resolution for Blob.empty as an immortal canonical empty Blob, not a zero-argument function. Lower ordinary constructors and transformations to fresh Blob handles, preserve handle identity when a value is passed or rebound, and admit Blob equality using handle identity: the same handle and repeated Blob.empty references compare equal, while separately constructed equal byte sequences compare unequal. Apply the same rule recursively inside equality-capable containers and render in-process values as interpreter-style ephemeral Blobs.

## Work item 01a000d488fe7d53ac1519572a12751d

## Work item 01a000d488fe753bb9a558afbed1f47c
