The feedback asks for the undefined phrase “lowercase hyphenated D text” to be replaced throughout with an exact, user-visible UUID text definition.

## What changed

- Replaced every use of “lowercase hyphenated D text” with “36 ASCII characters: lowercase hexadecimal digits grouped 8-4-4-4-12 with hyphens.”
- Added a canonical example UUID and made formatting, rendering, serialization, test, and documentation outcomes use the explicit format.
- Kept the UUID(UInt128) representation and all previously scoped parity work intact.

## Why

“D” is a host-format identifier, not a self-contained public contract. Stating the exact character count, alphabet, separator positions, and example makes the required observable behavior unambiguous across compiler backends and independent of host formatting terminology.
