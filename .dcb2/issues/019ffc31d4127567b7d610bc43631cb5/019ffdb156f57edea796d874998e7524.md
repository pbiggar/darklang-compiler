# Design brief

## Problem

All comparisons were revalidated at compiler HEAD 9195f26d0f1d32b5345bc6020cf569674951d8f6 against darklang/dark 04fbe9dcc995c6188757d583e273cbd30a3e2d3d, using DCB1 report 8a402797 only as starting evidence. The compiler still treats UUIDs as strings, lacks canonical parsing, preserves noncanonical spelling, and consequently differs in accepted input, equality, formatting, serialization, and error shape.

## Goals

- Match the interpreter’s UUID parsing and Result behavior, with canonical ParseError containing only BadFormat.
- Represent UUID as a distinct value throughout generation, parsing, equality, formatting, and serialization.
- Retain the requested legacy parser and unsupported-error case only as an explicitly separated compiler compatibility extension.

## Proposed solution

Introduce UUID as a primitive semantic type backed by a stable 128-bit payload. Parsing should accept and reject exactly the forms accepted by the pinned interpreter, normalize successful values, and return only BadFormat on failure. Generation should produce version-4 UUID values; equality should compare UUID payloads; formatting and public serialization should emit the canonical lowercase hyphenated form; deserialization should reconstruct UUID rather than String. Keep the legacy parser and additional error case behind a clearly documented compatibility boundary that delegates to canonical behavior and does not alter the canonical type or contract.

## Success criteria

- Canonical parsing produces matching success and failure results for the same source inputs on both revisions.
- Generated and parsed values are observably UUIDs, cannot be used as strings without formatting, and compare by UUID identity rather than input spelling.
- Formatting and serialization consistently emit canonical lowercase hyphenated text and round-trip back to equal UUID values.
- ParseError exposes exactly BadFormat on the canonical surface.
- The legacy compatibility surface remains available but is clearly classified as a compiler-only extension.
