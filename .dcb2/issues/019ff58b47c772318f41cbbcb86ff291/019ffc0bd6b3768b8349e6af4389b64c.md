a fundamental difference between the compiler and the interpreter is that the compiler is type-checked in advance. Thus, the interpreter carries certain behaiours where type checking is done lazily and if it doesn't come up the program can continue, and if it does come up, it errors at run-time. None of that is necessary for the compiler because of the compile-time type checks. Do not weaken compile-time type checks, and do not introduce features that are unnecessary due to the type checker.
