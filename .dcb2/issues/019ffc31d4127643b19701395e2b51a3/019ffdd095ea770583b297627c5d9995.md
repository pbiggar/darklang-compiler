# Design brief

## Problem

At C@d8814ed2557c9108ad91de0503a6631972fc95d1, compiled programs lack the public polymorphic equality and explicit output prelude provided by I@04fbe9dcc995c6188757d583e273cbd30a3e2d3d, and generic equality can lose structural semantics.

## Goals

- Match interpreter equality for every shared supported value, including nested structures and opaque identity rules.
- Preserve ahead-of-time rejection of incompatible types as an intentional phase divergence, while classifying compiler-only values explicitly.
- Match verbatim text output, newline behavior, ordering, return value, and observable effects using minimal native primitives.

## Proposed solution

Use the pinned revisions as the parity contract and expose portable prelude compositions over narrow native equality and raw-output boundaries. Specialize equality from statically established types and route operators and public equality through one exhaustive structural contract, without runtime cross-type dispatch. Keep negation, newline variants, and ordered list traversal portable. Treat compiler-only value categories and host-level result presentation as separate, explicitly documented non-parity behavior.

## Success criteria

- Same-source equality produces interpreter-equivalent results for every shared supported value and nested combination, while incompatible operands fail during compilation.
- Explicit output emits identical bytes, newline counts, and line order, returns Unit, and preserves left-to-right effects.
- All retained behavior is revision-pinned, with compiler extensions and intentional divergences explicitly classified.
