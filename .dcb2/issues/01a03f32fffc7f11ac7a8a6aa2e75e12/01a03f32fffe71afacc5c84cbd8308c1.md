# Make invariant-load LICM memory-safe and measurable

Hoist only scalar heap loads proven invariant across a loop without moving loads across writes.

## Constraints

- Treat HeapStore, raw writes, calls, allocation, reference-count operations, and unknown memory effects as load-availability barriers.
- Require an invariant SSA address, exact field offset, scalar type, unique preheader, and reducible natural loop.
- Add failing MIR/LIR and generated-code tests for loop-local writes, aliased addresses, calls, and valid invariant loads; run ./run-tests --ai and ./benchmarks/run_benchmarks.sh --verify routine.
- Retain only safe cases with a repeatable net benefit; update docs/classic-optimizations.md and remove temporary benchmark inputs.
