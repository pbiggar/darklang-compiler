# Implementation plan

The current type checker treats `Div` as a general numeric operator. Stdlib and benchmark sources rely on that extension, including `Int64.divide`, fixed-width division helpers, decimal conversion, byte encoding, and benchmark algorithms. Float divisions already use the same syntax and remain in scope unchanged.

## Work item 01a0548c30977605b5dc9076c18db1ef

Title: Make slash Float-only

Category: other

Evidence: `1.5_TypeChecking.fs` currently groups `Div` with arithmetic operators accepted for integer and Float types.

Outcome:

Type checking accepts `Div` only when both operands are Float and retains existing Float lowering.

## Work item 01a0548c30977122a72c7af458ff354f

Title: Migrate compiler-owned integer divisions

Category: other

Evidence: Integer `/` occurs in numeric stdlib modules, `Bytes.dark`, `AWS.dark`, and benchmark sources including collatz, edigits, quicksort, primes, and spectral norm.

Outcome:

Stdlib and benchmark integer quotients call the existing matching `Stdlib.IntX.divide` function; Float expressions remain `/`.

## Work item 01a0548c30977b6daf8515344bb6bf07

Title: Prune and realign tests

Category: other

Evidence: `integers.e2e`, `variables.e2e`, `functions.e2e`, benchmark E2Es, and list parity currently exercise the compiler-only operator.

Outcome:

Delete direct integer-`/` success coverage, migrate behavior tests that need named division, and add the smallest rejection regression for integer `/`.

## Work item 01a0548c30977fe885c9f5e624dae987

Title: Update parity documentation

Category: other

Evidence: `docs/darklang-differences.md` explicitly records integer `/` as a compiler extension.

Outcome:

Remove integer `/` from the compiler-only difference ledger and document Float-only slash parity.

## Conversation response

Implement the narrow `/` parity change: `/` becomes Float-only; integer division remains solely `Stdlib.IntX.divide`. All compiler-owned integer uses in stdlib and benchmarks migrate to the matching named function, while tests that only prove integer `/` are removed.
