# Reuse ARM64 release-plan summaries

Remove repeated release-plan summarization from the ARM64 code-generation hot path.

## Constraints

- Scope only to ARM64 code generation; retain one immutable release-plan summary cache shared by requirement collection and helper-dependency queries, without folding in other metadata-scan changes.
- First profile summary recomputation and remove all profiling or instrumentation afterward.
- Run 10 comparable before and 10 after `-vv` fasta compilations; report raw Code Generation timings, medians, and absolute and percentage deltas.
- Because benchmark timings drove selection, report before/after Code Generation and total-compilation deltas for every routine benchmark program.
- Run 10 comparable before and 10 after wall-clock executions of `./run-tests --ai`; report raw results, medians, and deltas.
- Require byte-identical symbolic ARM64 output and binaries, a passing `./run-tests --ai`, `./benchmarks/run_benchmarks.sh --verify routine`, and unchanged instruction counts; reject neutral, noisy, or regressive results.
