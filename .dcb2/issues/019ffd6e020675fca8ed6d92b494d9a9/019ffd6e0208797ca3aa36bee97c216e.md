# Linearize AST-to-ANF sibling bindings

Reduce AST-to-ANF allocation by accumulating child binding chunks without repeatedly appending growing prefixes.

## Constraints

- Limit retained changes to the shared sibling-conversion hot path used by call arguments and tuple elements in pass 2; retain one functional accumulation representation.
- Use an isolated worktree with a pinned revision, toolchain, host conditions, warm-up policy, and alternating run order.
- Profile accBindings @ childBindings copies first and discard the trial unless they materially contribute to AST-to-ANF time.
- For every routine benchmark program, collect 10 paired before/after -vv runs and report raw AST -> ANF and total-compilation results, medians, absolute deltas, and percentage deltas.
- Collect 10 paired before/after ./run-tests --ai wall-clock runs with raw results, medians, and deltas; require all runs to pass.
- Require identical ANF, binaries, evaluation order, benchmark outputs, and instruction counts; run ./run-tests --ai and ./benchmarks/run_benchmarks.sh --verify routine and report the RESULTS.md ratio.
- Retain only a clear improvement beyond a predeclared noise threshold; record discarded accumulator alternatives and remove all profiling and instrumentation.
