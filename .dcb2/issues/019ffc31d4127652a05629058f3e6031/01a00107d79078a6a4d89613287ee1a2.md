# Implementation plan

Revalidation against C@51093e0a8e31fe45a9aa79a317fbefd6b74fbcc3 and I@04fbe9dcc995c6188757d583e273cbd30a3e2d3d confirms one contained compatibility slice. The frozen interpreter exposes a data-only Cookie record and a String-based responseWithJson; its cookie encoder and tests are commented out. Html.s is the sole required compiler-only extension, and no intentional behavioral divergence or generic JSON runtime is needed.
