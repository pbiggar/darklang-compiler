# Trial dominated scalar heap-load reuse

Measure whether exact scalar heap loads can be reused across barrier-free dominated blocks with a net routine-profile benefit.

## Constraints

- Restrict reuse to an identical SSA address, field offset, and scalar value type whose defining load dominates the replacement.
- Treat calls, heap allocation or stores, raw memory operations, reference-count operations, and non-scalar values as availability barriers.
- Preserve SSA dominance, value typing, ownership behavior, and generated-code semantics.
- Create focused failing MIR/LIR or generated-code tests before the transformation, then run ./run-tests --ai and ./benchmarks/run_benchmarks.sh --verify routine.
- Keep docs/classic-optimizations.md current with retained or rejected evidence and remove temporary benchmark inputs.
