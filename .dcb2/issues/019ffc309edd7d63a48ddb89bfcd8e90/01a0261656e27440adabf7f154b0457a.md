For the most part, Builtins in the interpreter were done using F# or dotnet libaries or builtins. However, we don't have that available in the compiler. Thus, each feature from Builtins will have to be implemented using Darklang code, or by using Syscalls.

Note, a bunch of these or similar have been implemented in the Internals module. Those should move to the Builtins module to match the interpreter
