## Problems

## Solution

Both revisions resolve to 218523badb342d4fb246ddd1e1c95bf349542a65, so no performance difference can be attributed to this candidate. ## Implementation

- No files changed.
- Preserved the existing uniform-literal direct-call specialization unchanged.
- Preserved the rejected unused-parameter elimination as absent.

### Algorithm

1. Analyze internal direct-call sites.
2. Exclude address-taken and closure-target functions.
3. Identify parameters receiving one identical literal at every known direct call.
4. Remove those parameters, substitute literals into bodies, and rewrite normal, borrowed, and tail calls.
5. Do not retain unused-parameter elimination because it previously measured neutral.

### Example

For a recursive group where every call passes `7` as a second argument, the retained transformation changes `f(x, 7)` to `f(x)` and substitutes `7` in `f`'s body; indirect uses retain the original signature.
