# Align DateTime and Duration

Match the interpreter’s distinct DateTime value and duration arithmetic contracts.

## Constraints

- DateTime differing scope: addSeconds, subtractSeconds, toSeconds, fromSeconds, subtract, year, month, day, weekday, hour, minute, second, toMilliseconds, fromMilliseconds, addMilliseconds, subtractMilliseconds, millisecond, and subtractMs must use Int and a distinct DateTime value rather than Int64 aliasing.
- Duration missing scope: parse with its Int result, recognized units, and exact error contract.
- Evidence: C@51093e0a8e31fe45a9aa79a317fbefd6b74fbcc3 src/DarkCompiler/stdlib/DateTime.dark:6-305 aliases DateTime to Int64 and has no Duration module; I@04fbe9dcc995c6188757d583e273cbd30a3e2d3d packages/darklang/stdlib/{dateTime,duration}.dark and backend/testfiles/execution/stdlib/{date,duration}.dark.
