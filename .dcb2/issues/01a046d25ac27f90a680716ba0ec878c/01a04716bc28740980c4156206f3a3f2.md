- Documented the rejected trial and repair in `docs/classic-optimizations.md`.

### Algorithm

1. Match only direct self recursion returning an Int64 multiplication result.
2. Require exactly one self call, primitive bindings, and an Int64 parameter/literal factor.
3. Thread a one-initialized accumulator using wrapped multiplication.
4. Multiply the base result by the accumulator and let existing TCO lower the helper self-call to a loop.
5. Reject subtraction and bitwise recursive-result forms pending separately tested and measured designs.

### Example

Before retained behavior: `n * factorial(n - 1)` recursively returns then multiplies. After: `factorial$trmo(n, acc)` computes `acc * n`, tail-calls itself with `n - 1`, and returns `acc * 1` at the base case. The rejected trial no longer rewrites `recursiveSubtract(n - 1, step) - step` or bitwise forms.
