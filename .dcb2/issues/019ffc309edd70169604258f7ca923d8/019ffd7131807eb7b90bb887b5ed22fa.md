# Design brief

## Problem

At compiler b2e1f3d1e4ce0338d4c4662db9a1326f2e2cb899, comparison behavior is not governed by one verified contract matching interpreter 04fbe9dcc995c6188757d583e273cbd30a3e2d3d.

## Goals

- Match interpreter equality and ordering across the required scalar, structural, nested, Dict-exposed, and function-value categories.
- Preserve ahead-of-time rejection of invalid or cross-type comparisons without adding unnecessary runtime polymorphism.
- Align nominal identity, recursive equality, numeric ordering, NaN, signed zero, and public failure behavior.
- Use interpreter operator spellings and classify retained compiler extensions or intentional divergences explicitly.

## Proposed solution

Adopt a revision-stamped, interpreter-derived comparison contract. Enforce admissibility during ahead-of-time type checking, then apply consistent semantics through operator lowering and statically valid generic comparison: recursive equality for compatible values, nominal identity where required, source identity for functions, and ordering only for supported same-typed numeric values. Treat earlier compiler rejection of interpreter runtime-invalid comparisons as an intentional AOT divergence, preserve equivalent public diagnostic meaning, cover exposed Dict equality while leaving key admissibility to Dict work, and remove comparison aliases.

## Success criteria

- Same-source comparisons using interpreter syntax produce equivalent results across every required value category and nested combination.
- NaN is unequal and unordered, signed zeros compare equal, and ordinary numeric ordering matches the interpreter.
- Records and constructors respect nominal identity, compound values compare recursively, and functions use interpreter-equivalent source identity.
- Unsupported and cross-type comparisons fail during compiler type checking with the phase difference and public diagnostic meaning documented.
- Dict equality matches exposed interpreter behavior without expanding this issue into Dict key policy.
- Only interpreter comparison spellings remain, with every extension or intentional divergence explicitly recorded.
