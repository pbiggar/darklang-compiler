## Detailed replacement plan

Current main is `a9249c743c80629857e43a25f1cdc76ce175a50a`. It still has the legacy string-keyed inference paths (`consolidateBindings` and `inferTypeArgs`) in `1.5_TypeChecking.fs`; no structural `TypeInference` layer is present. The requested implementation therefore remains necessary rather than being superseded by current-main integration.

Every parity comparison will record: compiler evidence `b2e1f3d1e4ce0338d4c4662db9a1326f2e2cb899`, interpreter evidence `04fbe9dcc995c6188757d583e273cbd30a3e2d3d`, and the implementation-base commit used for the probe. DCB1 `8a402797` remains an inventory only.

1. Establish a revision-pinned executable parity ledger before changing semantics. For each probe, record source text, parser accepted/rejected status, inferred relationships, result, diagnostic category, and parser-versus-type phase. Cover declaration and call syntax, implicit signature variables, bindings, lambdas and partial application, recursive groups, repeated variables, annotations, constructors/patterns, aliases, empty values, ambiguity, and self-application. Mark AOT-only earlier failures explicitly rather than treating them as interpreter equivalence.

2. Align source syntax at the parser/type-reference boundary. Accept apostrophized declaration variables and interpreter-style implicit variables occurring in function signatures; retain adjacent explicit call type arguments only where the interpreter accepts them and require exact arity. Reject legacy bare lower-case type references and unsupported value annotations in the parser, not later in type checking. Preserve already-landed recursive declaration syntax and identities.

3. Introduce a structural inference representation. Separate source variables, inference variables, quantified variables, and rigid annotation/skolem variables in a dedicated module. Define substitutions, free-variable calculation, scheme generalization, fresh instantiation, source-type conversion, and structured diagnostics. Generated variable spellings must not encode solver state.

4. Replace the legacy matching/consolidation routes with a single substitution-threading solver. Unify functions, tuples, lists, streams, dictionaries, records, aliases, nominal sums, constructor payloads, runtime errors, and unknowns through common rules. Enforce arity, nominal identity, repeated-variable consistency, substitution composition, and occurs checks. Surface distinct mismatch, repeated-variable, infinite-type, ambiguous-inference, annotation-mismatch, unknown-type, and explicit-type-argument-arity errors.

5. Make expression typing scheme-aware. Store schemes in typing environments; instantiate each polymorphic use freshly; generalize only independently polymorphic non-recursive bindings whose variables are not free in the surrounding environment. Preserve a single runtime closure allocation while elaborating fresh source-level call instantiations. Type recursive and mutually recursive groups from monomorphic prebindings or rigid declared signatures, solve their bodies as a group, and generalize only outside the group. Reject unsupported polymorphic recursion at source type-check time.

6. Enforce annotations and nominal generics through the same solver. Skolemize declared annotation variables; prove inferred bodies satisfy the complete declared scheme rather than selected call-site specializations. Apply the same relationship to implicit signature variables, repeated variables, return constraints, generic aliases, records, sums, constructors, and constructor patterns. Ensure unresolved representation-relevant monotypes fail before lowering, while genuinely quantified relationships remain source-level schemes.

7. Make type checking the sole source-typing owner and constrain monomorphization to solved internals. Emit elaborated expressions and closed instantiation metadata from type checking. Remove ANF fallback inference/defaults for call results, tuple/list/record fields, and `Unit`; ANF must consume the elaboration and reject unsolved backend representations. Compute specialization closure from closed instantiations, including recursive and higher-order dependencies, without changing source names, acceptance, results, or closure identity.

8. Replace obsolete generic regression fixtures and documentation. Add same-source E2E coverage for independent polymorphic reuse, partial applications, repeated and nested constraints, recursive versus completed bindings, annotations, generic constructors/patterns, aliases, empty/container ambiguity, occurs checks, and error phase. Migrate existing tests that rely on unresolved specialization fallbacks to explicit closed instantiations or explicit ambiguity failures. Update `docs/features/generics.md`, `docs/features/type-checking.md`, and the parity ledger with grammar, schemes, recursion policy, ambiguity policy, diagnostics, evidence locations, and declared AOT divergences.
