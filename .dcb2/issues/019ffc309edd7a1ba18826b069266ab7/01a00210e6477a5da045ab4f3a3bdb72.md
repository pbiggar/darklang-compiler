# Implementation plan

Revalidation used compiler b2e1f3d1e4ce0338d4c4662db9a1326f2e2cb899 and darklang/dark 04fbe9dcc995c6188757d583e273cbd30a3e2d3d. The current compiler tree has partially aligned declaration, lambda, and ADT syntax, but source typing still relies on string-named variables, ad hoc unification, monomorphic environments, specialization-driven checking, and repeated ANF inference. The change remains one contained compiler delivery.

## Work item 01a00210e6477ea89e5edad3ffd1e383

## Work item 01a00210e6477166a022d4d669a2ca64

Title: Type recursive and mutually recursive definitions coherently

Category: behavior

Evidence: Compiler functions may be mutually recursive, but current generic checking validates source bodies and discovered concrete specializations separately at src/DarkCompiler/passes/1.5_TypeChecking.fs:5865-6821. Outcome:
