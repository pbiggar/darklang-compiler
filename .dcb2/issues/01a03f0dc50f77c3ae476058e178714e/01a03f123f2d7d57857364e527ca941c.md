## How it works

Baseline MIR contains six nqueenSolve_body phis and twelve explicit logical source copies across L3/L4. Before codegen, register allocation coalesces the carried values into X21–X26; both backedges are direct branches with no transport MOV instructions. A special direct-tail-loop representation would only alter IR shape, add ownership/allocator complexity, and cannot reduce an already-zero emitted cost. No compiler candidate, new regression, benchmark run, or commit was created; the required rejection record and active-investigation cleanup remain as uncommitted documentation changes.

## Algorithm

1. Lower self-tail recursion to the existing loop-header phi representation.
2. Allocate all six carried values consistently to X21–X26.
3. Coalesce each phi source with its destination.
4. Emit only the updated computation and branch back to nqueenSolve_body; no backedge transport move remains.
