# Implement DateTime and Duration parity

Provide a distinct DateTime value and canonical duration parsing and arithmetic.

## Constraints

- Replace the public Int64-alias behavior with a distinct DateTime runtime value and align addSeconds, subtractSeconds, toSeconds, fromSeconds, subtract, year, month, day, weekday, hour, minute, second, toMilliseconds, fromMilliseconds, addMilliseconds, subtractMilliseconds, millisecond, and subtractMs to Int signatures.
- Add Duration.parse with the interpreter's recognized units, Int result, whitespace and numeric handling, and exact error contract.
- Reuse portable DateTime and Duration wrappers while implementing clock, epoch, calendar, and timezone-independent conversion primitives natively; cover type separation as well as computed values.
