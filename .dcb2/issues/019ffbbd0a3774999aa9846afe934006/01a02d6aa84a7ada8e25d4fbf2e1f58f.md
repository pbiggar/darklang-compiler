# Trial result

A clean isolated checkpoint reduces deterministic topology work, but bounded compiler timing samples were noisy and did not establish an overall improvement. Canonical routine benchmark: equal.

## Evidence

## What changed

Committed one scoped MIR optimizer change: build an immutable LoopTopology once per reachable cyclic optimizer iteration and pass it to affine induction strength reduction and LICM; added an E2E canonical affine-loop case.

## How it works

Baseline structurally performed two natural-loop scans and four predecessor builds across affine reduction and LICM; the retained candidate performs one of each and does not reuse topology across later CFG-changing passes. The only attempted design was this per-iteration immutable summary. Two warmed alternating fasta samples had conflicting timing results, so the required ten-pair matrices, binary/IR corpus comparisons, full test suite, and routine benchmark verification were not completed; no overall performance claim is justified.

## Algorithm

1. Detect whether the current CFG has a reachable cycle. 2. If so, build predecessors once. 3. Derive natural loops from that predecessor map once. 4. Give the immutable summary to affine induction reduction. 5. Reuse the same summary for immediately following LICM, since affine changes instructions but not CFG edges. 6. Discard it before counted-loop unrolling, DCE, and CFG simplification.
