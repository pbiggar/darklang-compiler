# Design brief

## Problem

At workspace HEAD f336467f5c96a15421ef52c8fb966bfd3dfa2d9c, the pinned compiler evidence b2e1f3d1e4ce0338d4c4662db9a1326f2e2cb899 diverges from interpreter 04fbe9dcc995c6188757d583e273cbd30a3e2d3d because compiler ADTs use a flattened, single-payload model and compiler-only syntax that can lose interpreter arity, namespace, typing, and nominal-identity semantics.

## Goals

- Use the pinned interpreter’s public ADT behavior as the contract.
- Support ordered zero-or-many constructor fields, recursive and generic types, aliases, qualified construction, and type-directed patterns.
- Match duplicate, collision, and invalid-declaration outcomes while preserving nominal identity in rendering and equality.
- Remove compiler-only ADT declarations and constructor forms, retaining only documented AOT-specific error timing.

## Proposed solution

Adopt one interpreter-shaped ADT model across declarations, resolution, typing, lowering, and observable runtime operations. Represent ordered case fields and resolved module/type/case identities; validate declarations and instantiate aliases, recursion, and generics consistently; require interpreter construction syntax while resolving patterns from the scrutinee type; statically enforce exact arity and field types; and evaluate valid fields exactly once from left to right. Carry canonical nominal identity into generated rendering and equality instead of relying on unqualified names or local tags. Migrate affected sources before removing the old forms. Earlier compile-time rejection of invalid programs is the sole intended AOT divergence; no compiler-only ADT syntax is retained.

## Success criteria

- Valid nullary, multi-field, tuple-field, recursive, generic, alias, and module-qualified programs produce interpreter-equivalent values and output.
- Duplicate definitions, constructor collisions, malformed declarations, unknown cases, and incorrect arity or field types have the same semantic outcome, apart from documented earlier AOT rejection.
- Constructors from distinct nominal types or modules never collapse in resolution, rendering, or equality, while aliases preserve interpreter identity.
- Payload expressions execute exactly once in interpreter order, and migrated compiler-only ADT syntax is no longer accepted.
