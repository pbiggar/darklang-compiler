# Trial result

The retained isolated candidate skips the no-op ANF rebuild and reduced fasta ANF Optimizations median by 14.15 ms (12.42%) with identical optimized ANF and binaries. Canonical routine benchmark: equal.

## Evidence

## What changed

Combined TempId collection and inverted-literal-branch detection in rewriteInvertedBoolLiteralBranchesInProgram; return the original program when no target exists, otherwise retain the existing rewrite. Added e2e coverage for true and false execution of an inverted literal branch.

## How it works

Fasta has no target rewrite but previously paid a 3.19 ms fresh-ID scan plus a 3.42 ms rebuilding traversal. The retained single analysis preserves fresh-ID safety and bypasses allocation/rewrite work when unnecessary. Fasta samples improved despite shared-load noise; target-path behavior is covered by e2e. Residual risk is limited to the new analysis matching TempId-use collection semantics.

## Algorithm

1. Traverse functions and main once, collecting all bound/used TempIds and detecting If(cond, Return false, Return true). 2. If no target is found, return the input Program unchanged. 3. If a target exists, derive the fresh VarGen from the maximum collected TempId. 4. Run the existing bottom-up rewrite unchanged.
