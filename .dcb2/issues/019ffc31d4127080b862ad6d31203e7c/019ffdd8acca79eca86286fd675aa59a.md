# Design brief

## Problem

At compiler HEAD 346ad9d763d124749a332f4f128b30e7e04ff7ea, the HTTP runtime family remains absent relative to [darklang/dark HEAD 04fbe9dcc995c6188757d583e273cbd30a3e2d3d](https://github.com/darklang/dark/commit/04fbe9dcc995c6188757d583e273cbd30a3e2d3d); DCB1 report 8a402797ccccda0ca47b516b356ae1de4d670038 is incomplete starting evidence only.

## Goals

- Match observable buffered-client, streaming-client, SSE, routing, configuration, and server behavior.
- Provide bounded resource ownership, cancellation, cleanup, body enforcement, and server lifecycle across supported native targets.
- Preserve AOT-appropriate static checking and explicitly classify every extension or intentional divergence.

## Proposed solution

Port the interpreter’s portable HTTP behavior directly into Dark, adapting only where required by static compilation, and introduce a native runtime boundary for HTTP/TLS transport, owned streaming handles, cancellation, cleanup, bounded request ingestion, and server execution. Treat the pinned interpreter behavior as authoritative; keep native differences contained and revision-stamped, with no compiler-only additions unless required by AOT or platform lifecycle constraints.

## Success criteria

- Same-source programs produce equivalent requests, responses, headers, authentication values, and structured errors.
- Streaming remains incremental and SSE results are invariant across chunk boundaries, multiline input, blank blocks, and end-of-stream.
- Routing and server behavior match the baseline, including body-limit responses and lifecycle callbacks.
- Every terminal path predictably releases transport and server resources.
- Parity evidence records both exact revisions and labels all extensions and intentional divergences.

## Open questions

- Which native HTTP/TLS substrate can support all target platforms without changing observable protocol or error behavior?
- Which cancellation and signal semantics should be documented as intentional divergences where interpreter behavior is host-dependent or internally inconsistent?
