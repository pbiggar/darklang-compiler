# Trial result

Retained a committed MIR CSE candidate that removes duplicate proven-effect-free scalar direct calls with deterministic focused reductions. Canonical routine benchmark: 0.964176× overall.

## Evidence

## Problems

Eliminate repeated proven-pure scalar direct calls when IR and benchmark evidence show a net win.

## Solution

Previously MIR CSE only reused binary and unary instructions. The candidate reuses only direct calls to whole-program-proven effect-free functions with identical operands and non-owning scalar results. Indirect calls, managed results, throwing callees, and barrier-crossing reuse are excluded. Residual risk is limited to broader repository validation, which was intentionally left to the worker per instruction.

## Implementation

- Added exact direct-call CSE keys: callee identity, ordered operands, and scalar return type.
- Reused existing whole-program effect-free facts for CSE, not only LICM.
- Replaced eligible duplicate calls with typed moves locally and through safe dominator successors.
- Cleared direct-call availability at other calls, allocation/memory/runtime instructions, and ownership barriers.
- Added focused MIR tests and documented the optimization.

### Algorithm

1. Compute the existing effect-free-function fixed point when MIR CSE is enabled.
2. For each eligible direct scalar call, form a key from callee name, ordered operands, and return type.
3. Replace a matching available call with a typed move from the original result.
4. Otherwise record the call as available and export it through the dominator tree.
5. Clear direct-call availability at a different call or any allocation, memory/runtime, or ownership barrier.
6. Pass immutable availability only from dominators to children, never siblings.

### Example

Before in the no-inline loop body: `v23 <- Call(pure, [v21]); v24 <- Call(pure, [v21]); v27 <- v26 + v24`. After: `v23 <- Call(pure, [v21]); v27 <- v26 + v23`. The exact callee, operand, and `TInt64` result match, so one call is eliminated while preserving the first call’s evaluation point.
