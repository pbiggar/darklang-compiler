## Implementation

- Candidate colors non-interfering integer spills into shared negative stack slots.
- Candidate derives aligned frame size from the deepest assigned slot.
- Candidate adds one allocator-level interference test and documentation, but no ARM64/x64 generated-code tests.

### Algorithm

1. Preserve physical-register assignments.
2. Collect spills in domain order.
3. For each spill, inspect already assigned interference neighbors.
4. Assign the first unused negative 8-byte offset.
5. Align the deepest used offset to 16 bytes.

### Example

Three forced non-interfering spills change from -8/-16/-24 (32-byte aligned frame) to shared -8 (16-byte frame); a three-way call-live clique remains distinct. This allocator-level example does not establish generated ARM64/x64 stack traffic.
