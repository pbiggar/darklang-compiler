Note that builtins are done differently in the compiler. In the interpreter, they're implemented via F# functions and called via the Builtins module. In the compiler, they could also use the Builtins module I suppose, but they might be different builtins due to support for eg List or Dict implementations.

Note that the compiler implements a lot more as Dark code rather than relying on dotnet stuff.

For Dict, keep the whole implementation but restrict the types to match the interpreter's limitations.
