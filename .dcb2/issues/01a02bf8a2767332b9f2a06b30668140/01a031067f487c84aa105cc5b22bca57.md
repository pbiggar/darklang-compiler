# Implementation plan

The intrinsic registry is currently exposed wholesale as `CompilerExtension` candidates; documented public divergences span Path/File, Float/Math, text, Bytes/Blob/Crypto, and `Html.s`. The accepted boundary retains only compile-time type and exhaustiveness diagnostics.

## Work item 01a031067f477987a00ad66f8a5da5b8

Title: Remove source-reachable compiler-only extensions and retain only parity semantics

Category: behavior

Evidence: `Stdlib.fs:10-276` registers intrinsic modules and raw-memory helpers; `1.5_TypeChecking.fs:6972-7020` exposes every registry entry as `CompilerExtension`; `2_AST_to_ANF.fs:346-352,5709-5714,9488-9493` folds `Stdlib.Path.tempDir`; `stdlib/Path.dark:18-21` already defines `"/tmp"`. Public extension inventories are documented in `docs/text-parity.md:78-89`, `docs/float-math-parity.md:40-50`, `docs/blob-parity.md:66-80`, `docs/cli-parity.md:61-79`, `docs/html-http-parity.md:24-36`, and `docs/name-resolution.md:84-100`; affected coverage includes `e2e/file_io.e2e:116-120`, `bytes.e2e`, `floats.e2e`, and `html_http.e2e`.

Outcome:

Create failing E2E coverage for retained parity behavior and rejection of removed extension names; audit every `Stdlib` registry entry, documented extension, declaration, lowering case, and extension-specific test. Replace each public fold or intrinsic that has a target-language equivalent with that ordinary implementation, including making `Stdlib.Path.tempDir()` evaluate its existing `"/tmp"` Dark definition and deleting both constant-folding call sites. Remove public declarations, resolver registrations, lowering paths, documentation claims, and tests for APIs with no parity counterpart, including the documented Char/String, Float/Math, Bytes/Base64/Crypto, legacy File/Path, and `Html.s` surfaces. Rewire compiler and stdlib implementation dependencies to private intrinsics, prevent private names from source resolution, and preserve only semantics-preserving compiler optimizations plus compile-time type/exhaustiveness diagnostics. Update affected E2E fixtures to use parity APIs, then run the full test suite and routine benchmark profile.
