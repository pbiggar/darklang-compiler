# Remove as many compiler-extensions as possible

We want to remove compiler extensions. THe only difference - if possible - should be timing. The compiler does some things at compile-time, not run-time, such as type-checking, ad exhaustiveness checking. For other stuff, we should remove whatever extensions are there.
