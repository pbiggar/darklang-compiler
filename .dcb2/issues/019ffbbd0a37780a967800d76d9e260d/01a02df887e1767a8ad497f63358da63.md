## Algorithm

1. Read each successor block from the current terminator. 2. Recursively rewrite only consecutive leading Phi instructions. 3. For each rewritten Phi, rename sources originating at the current label. 4. Return the remaining non-phi suffix unchanged. 5. Replace the successor block with the updated prefix plus original suffix.
