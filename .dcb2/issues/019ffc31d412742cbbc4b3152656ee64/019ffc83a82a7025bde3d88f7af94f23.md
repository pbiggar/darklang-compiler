In general, we want to remove compiler-extensions and make it the same as the interpreter, with the exception that the compiler is type-checked and compiled ahead of time, and so that implies some behaviour. 

But different sets of functions and implementations should not be preserved simply because they are there. If there is some functionality that relies on them, they can be kept, but ideally they would be removed.
