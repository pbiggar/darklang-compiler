# Trial result

One-iteration peeling is structurally regressive for the canonical scalar loops already optimized by factor-two unrolling, so no compiler change was retained. No established-suite improvement was proven; overall multiplier: 1×.

## Evidence

## Problems

Determine whether one-iteration peeling exposes profitable existing MIR simplifications in canonical scalar loops.

## Solution

The pinned canonical `i * i` loop already receives MIR factor-two unrolling, executing two scalar bodies per header check. Its initial header-phi values are function parameters, so peeling cannot expose literal first-iteration operands to existing constant folding. A checked peeled body would also turn the residual CFG into more than two blocks, preventing the existing strict two-block unroller from applying. No safe, profitable candidate exists under the requested constraints.

## Implementation

- Added a documented no-improvement trial outcome to `docs/classic-optimizations.md`.
- Left compiler code and regression fixtures unchanged; removed the disposable probe input.

### Algorithm

1. Recognize the proposed shape: unique preheader, guarded two-block loop, one latch backedge, scalar-only instructions.
2. A semantics-preserving peel must clone the entry guard into the preheader to preserve zero-trip behavior.
3. On a successful guard, clone the first latch body and redirect header phi outside sources through that peeled body.
4. The residual loop then has an added peeled predecessor/block and no longer satisfies the existing factor-two unroller's exact two-block eligibility.
5. Since initial phi operands are parameters rather than literals, existing MIR simplifications remove no work; reject the transformation.

### Example

For `loop(i, limit, sum) = if i >= limit then sum else loop(i + 1, limit, sum + i * i)`, baseline MIR emits one header check followed by two scalar bodies in the unrolled pair. A peel must add `if i >= limit then exit else peeledBody` before entering the residual header. This preserves zero-trip behavior, but the residual has one scalar body per loop pass and cannot be factor-two unrolled; no first-iteration constant is exposed because `i` is a parameter.
