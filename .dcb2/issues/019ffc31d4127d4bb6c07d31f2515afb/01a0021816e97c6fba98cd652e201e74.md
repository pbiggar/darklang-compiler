# Implementation plan

Contained implementation scope based on source revalidation at compiler C@1ee3513aeded5eee6c4bac5779ee1aae9632f86b against interpreter I@04fbe9dcc995c6188757d583e273cbd30a3e2d3d. The focused runtime baseline remains C@51093e0a8e31fe45a9aa79a317fbefd6b74fbcc3, where decomposed "é" has compiled String.length 3 versus interpreter length 1; Unicode 17.0.0 is the accepted embedded-data version, with any revision-specific interpreter differences recorded as intentional divergences.

## Work item 01a0021816e97985b384c7607c760b22

Title: Define the text parity contract

Category: other

Evidence: C@1ee3513 has no text-specific parity document; I@04fbe9d public wrappers are packages/darklang/stdlib/{char,string,regex}.dark and runtime contracts are backend/src/Builtins/Builtins.Pure/Libs/{Char,String,Regex}.fs.

Outcome:

Add a revision-pinned Char, String, and Regex contract documenting canonical signatures, indexing units, normalization guarantees, failures, regex capture rules, Unicode version, and the explicit extension boundary. Classify Char.isLetter/isWhitespace/isAlphanumeric/toCode/fromCode and String.getByteAt/substring/take/drop/toCodepoints/codepointLength/fromCodepoints/toUpperCase/toGraphemes/graphemeLength/replace/equals as compiler extensions rather than parity APIs.

## Work item 01a0021816e973fca5fa71c6d103f08c

Title: Generate complete Unicode 17 data

Category: other

Evidence: src/DarkCompiler/unicode_data.dark:1-22 contains six case pairs and three numeric grapheme entries. scripts/generate_unicode_tables.py:13 pins Unicode 15.0.0 and reads only UnicodeData, SpecialCasing, and GraphemeBreakProperty; [Unicode releases](https://www.unicode.org/releases/) identifies 17.0.0 as the latest release.

Outcome:

Replace the minimal tables with deterministic, versioned generated Dark data for canonical decomposition and composition, combining classes, composition exclusions, grapheme-break properties, Extended_Pictographic and Indic-conjunct properties, full unconditional casing, contextual casing inputs, scalar/general categories, and White_Space. Represent properties with discriminated unions and compressed ranges, embed source hashes and counts, and provide a command-line regeneration/check mode requiring no installed Unicode files.

## Work item 01a0021816e97a1389ec16622dbe00f5

Title: Create the shared Unicode semantics layer

Category: behavior

Evidence: src/DarkCompiler/stdlib/String.dark:155-479 currently mixes unchecked UTF-8 decoding, hand-written Extend ranges, and two inconsistent simplified grapheme algorithms; Unicode.Data.__graphemeBreak is not used.

Outcome:

Add a pure Dark internal module implementing Unicode-scalar validation, strict UTF-8 traversal, NFC canonical decomposition/reordering/composition including Hangul, UAX #29 extended-grapheme segmentation including emoji ZWJ, regional indicators and conjunct rules, Unicode casing, and property lookup. Return typed Results or Options for invalid inputs and expose boundary-offset operations reusable by Char, String, and Regex.

## Work item 01a0021816e97d4f8a8164830bc3c194

Title: Enforce NFC and single-EGC value invariants

Category: type

Evidence: passes/1_Parser.fs:416-431 and passes/1_InterpreterParser.fs:494-511 validate chars with System.Globalization.StringInfo, while String/Char literals lower unchanged at passes/2_AST_to_ANF.fs:4826-4832 and 9010-9015; native StringConcat currently performs raw byte concatenation.

Outcome:

Generate compile-time validation data from the same Unicode inputs so both parsers stop depending on host StringInfo behavior.

## Work item 01a0021816e9705792ed9b9cf7711b05

Title: Separate internal byte operations from public text semantics

Category: behavior

Evidence: stdlib/String.dark:23-27 defines length as the allocation byte count and slice at 107-130 copies arbitrary bytes. Float.dark, Base64.dark, Blob.dark, Crypto.dark, and Uuid.dark currently use String.length/slice/take/drop for binary or ASCII parsing.

Outcome:

Introduce internal byte-length, checked byte-copy, and UTF-8-boundary helpers and migrate byte-oriented compiler stdlib consumers to them. Make public String.length EGC-indexed with Int results while keeping explicitly documented extension functions isolated; prevent substring/take/drop extension calls from constructing malformed UTF-8 Strings when a byte boundary splits a scalar.
