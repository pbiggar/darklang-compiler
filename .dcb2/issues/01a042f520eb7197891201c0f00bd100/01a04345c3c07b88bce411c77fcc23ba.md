# Trial result

Retained edge-sensitive MIR jump threading with a focused proof that removes one redundant conditional dispatch on established shared-successor edges. No established-suite improvement was proven; overall multiplier: 1×.

## Evidence

## Problems

Remove redundant conditional dispatches only where edge-sensitive CFG rewrites reduce generated control-flow instructions.

## Solution

The prior optimization only simplified a repeated condition when its successor had one predecessor. The retained rewrite redirects only the proven incoming edge, leaves the shared successor available to other predecessors, and updates destination phis. It requires a typed Boolean producer, an empty successor, and unambiguous phi sources; therefore it does not duplicate or reorder effects, reference-count operations, or allocations. Residual risk is limited to unusual malformed CFGs, which are rejected by the conservative matching gates.

## Implementation

- Added conservative edge-sensitive threading for empty, shared repeated-condition MIR blocks.
- Preserved destination phi values by adding the redirected predecessor as an identical phi source.
- Added true- and false-edge focused MIR regression tests.
- Documented the optimization in `docs/classic-optimizations.md`.
- Did not retain tail duplication: bounded duplication adds static control flow without a demonstrated reduction.

### Algorithm

1. Find a predecessor branch whose true or false edge establishes Boolean register `v`.
2. Require its target to be an empty block that immediately branches on the same typed Boolean `v`.
3. Select the outcome implied by the established edge.
4. Require destination phis to have exactly one source from the shared successor and none from the redirecting predecessor.
5. Redirect only that predecessor edge to the implied destination.
6. Append each destination phi's existing successor value under the redirecting predecessor label.

### Example

Before: `P: branch v ? S : A`; `S` also receives `A` and contains `branch v ? T : F`; `T: phi [(x,S)]`. On P's true edge, `v` is already true. After: `P: branch v ? T : A`; `S` remains for `A`; `T: phi [(x,S),(x,P)]`. The P-to-T path executes one conditional dispatch instead of two while preserving the phi-selected value.
