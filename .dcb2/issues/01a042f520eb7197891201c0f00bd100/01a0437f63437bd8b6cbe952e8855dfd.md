## Problems

Remove redundant conditional dispatches only where edge-sensitive CFG rewrites reduce generated control-flow instructions.

## Solution

The rewrite removes a redundant conditional dispatch only on an incoming edge that has already established the Boolean outcome, while leaving shared successor blocks reachable from other predecessors. Executable bytes, normalized MIR for edigits, and program output were identical. The focused pass timing was neutral/noisy, so the candidate remains preserved but is not an improvement.

## Implementation

- No files were edited, replaced, discarded, or integrated during measurement.
- Candidate already threads established edges through empty shared repeated-Boolean MIR branch blocks.
- Candidate preserves destination phi sources by adding the redirected predecessor with the successor’s existing value.

### Algorithm

1. Identify a typed Boolean branch edge with a known outcome.
2. Require its successor to be empty and branch again on that same Boolean.
3. Select the implied destination for the established edge.
4. Require unambiguous successor phi inputs and no existing redirected-predecessor source.
5. Redirect only that edge and extend destination phi sources with the equivalent value.

### Example

Before: `P: branch v ? S : A`; `S: branch v ? T : F`; `T: phi [(x,S)]`. After threading P’s true edge: `P: branch v ? T : A`; `S` remains reachable elsewhere; `T: phi [(x,S),(x,P)]`. This removes one dispatch on P→T while retaining the phi-selected value.
