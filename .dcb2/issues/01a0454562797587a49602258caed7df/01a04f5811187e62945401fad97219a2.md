## Evidence

## Problems

Remove needless leaf-function prologue and epilogue instructions when ABI requirements permit.

## Solution

The candidate conservatively removes x64 frame instructions only when no ABI-dependent frame behavior is needed. MIR, executable bytes, and program output were equal for the measured existing workload; therefore its timing difference is not attributable to the optimization. The focused zero-frame test passes, but no repeatable existing-workload improvement was proven.

## Implementation

- Candidate adds x64 zero-frame leaf eligibility after instruction selection.
- Candidate retains labels and `RET` while omitting RBP setup/restore only for eligible leaves.
- Candidate adds generated-code/native execution coverage and documentation.

### Algorithm

1. Select x64 blocks normally.
2. Reject `_start`, spills, callee-saved registers, tail calls, and generated calls.
3. Emit no RBP prologue/epilogue only for remaining leaves.
4. Retain the generated epilogue label and `RET`.
5. Otherwise retain normal frame lowering.

### Example

For a leaf returning `42`, the candidate omits `PUSH RBP; MOV RBP,RSP` and `POP RBP`, preserves `_epilogue_x64_zero_frame_leaf: RET`, and native execution returns exit status 42.
