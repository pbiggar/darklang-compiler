# Trial result

x64 zero-stack leaves now omit their needless RBP frame while preserving calls, tail transfers, labels, and entry-point behavior. No established-suite improvement was proven; overall multiplier: 1×.

## Evidence

## Problems

Remove needless leaf-function prologue and epilogue instructions when ABI requirements permit.

## Solution

The backend previously framed every x64 function. Eligible leaves can retain the caller-established stack and CALL-created return address, so removing `PUSH RBP; MOV RBP,RSP` and `POP RBP` removes two needless instructions. Selection-time CALL detection conservatively retains the normal frame whenever lowering introduces a call requiring System V stack alignment. `_start`, tail-call restoration, spill access, callee saves, generated labels, and `RET` behavior remain unchanged.

## Implementation

- Added x64 zero-frame eligibility after instruction selection.
- Omit RBP prologue/epilogue only for non-`_start` functions with zero stack size, no callee-saved registers, no tail calls, and no generated calls.
- Added generated-code plus native ELF execution regression coverage.
- Documented the optimization in `docs/classic-optimizations.md`.

### Algorithm

1. Translate CFG blocks normally.
2. Reject `_start`, nonzero stack size, callee-saved registers, and any tail-call form.
3. Scan selected instructions for `CALL` or `CALL_reg`; reject if present.
4. For remaining functions, emit no prologue/epilogue frame instructions while retaining the epilogue label and `RET`.
5. Otherwise retain existing frame lowering.

### Example

Before, leaf `X0 <- Mov(Imm 42); Ret` emitted `PUSH RBP; MOV RBP,RSP` before its body and `POP RBP` before `RET`. After, it emits the body followed by the existing `_epilogue_x64_zero_frame_leaf` label and `RET`; the caller receives native exit status 42.
