# Trial result

Eligible x64 leaf functions remove their RBP frame; the structural optimization is verified, while x64 runtime improvement remains unmeasured.

## Evidence

## Problems

x64 emitted an RBP prologue and epilogue even for leaf functions that need no stack frame. The optimization must preserve ABI alignment, return-address handling, labels, calls, tail transfers, callee saves, and `_start` behavior.

## Solution

After instruction selection, omit the x64 frame only for non-entry leaf functions with zero stack slots, no callee-saved registers, no tail-call restoration, and no generated calls. All other functions retain the existing frame lowering.

## Implementation

- Added conservative zero-frame eligibility to x64 lowering.
- Preserved the epilogue label and `RET` while removing `PUSH RBP`, `MOV RBP,RSP`, and `POP RBP` from eligible leaves.
- Added generated-code and QEMU-executed x64 regression coverage and documented the optimization.

### Example

A leaf returning `42` previously emitted two frame-setup instructions and one frame-restore instruction. The candidate emits the body, the existing epilogue label, and `RET`; the generated x64 ELF still returns 42 under `qemu-x86_64-static` on this ARM64 host.

### Verification

- Exact candidate repository tests: 8505/8505 passed in 2025.4s.
- The focused test inspects generated x64 instructions and executes the x64 ELF through QEMU, confirming correctness and the removed frame.
- No relevant x64 runtime benchmark has been run, so no runtime multiplier or performance win is claimed.

### Excluded measurements

- `fib quick / Code Generation` produced identical MIR, executable bytes, and output, proving it did not exercise frame elision.
- The canonical routine suite ran ARM64 code and was equal at `1×`; it is a non-regression check for this candidate, not evidence about this x64-only optimization.

The retained candidate is therefore structurally promising and verified for correctness, but runtime performance is **unproven** until measured on x64 hardware or with a guest-instruction-aware x64 measurement method.
