# Trial result

Retained an isolated candidate that fuses allocator integer and float liveness into one CFG fixed point while preserving focused mixed-domain output exactly.

## Evidence

## What changed

Replaced the allocation-path integer and float liveness solvers with a paired fixed point in src/DarkCompiler/passes/5_RegisterAllocation.fs; separate domains, GEN/KILL sets, phi-edge sets, and live sets are retained, but successor traversal is shared.

## How it works

The current code still performed two complete backward CFG traversals after shared block classification. The retained solution computes both independent domains in one loop, reducing successor/phi-edge traversal from two per CFG iteration to one while preserving each domain's original transfer equation. Standalone single-domain helpers delegate to the paired implementation. No instrumentation remains. Residual risk is broad-suite coverage: inherited experiment guidance prohibits canonical repository-wide validation at this stage, and the standalone fasta quick input currently fails before allocation because it references Stdlib.Internal.SkewList.getAt.

## Algorithm

1. Classify CFG blocks once. 2. Build independent integer and float domains, GEN/KILL sets, and predecessor phi-use bitsets. 3. Iterate blocks backward until neither domain changes. 4. Visit each successor once, accumulating its integer and float live-in sets plus matching phi-edge uses. 5. Apply the original per-domain live-in transfer equations. 6. Feed the unchanged live sets to existing interference and allocation stages.
