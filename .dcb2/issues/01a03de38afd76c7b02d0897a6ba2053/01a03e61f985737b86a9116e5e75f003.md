## How it works

The original candidate treated any cleanup-only suffix after a direct self call as safe to move before a loop backedge. Retry functions exposed this as unsound: unrelated string/generic cleanup was moved and led to exit 139. Alternatives considered were reverting all direct-call lowering or broadening ownership transfer further. The retained solution preserves the focused nsieve optimization: ordinary direct self calls qualify only when the complete suffix is exactly one DictHeap decrement and its register is reachable from a recursive Dict argument through prior MIR moves. Existing ANF TailCall lowering is unchanged. Complexity is linear in the short local cleanup/alias chain; residual risk is limited to the intentionally narrow single-Dict-cleanup recognizer.

## Algorithm

1. Preserve the existing ANF TailCall self-loop path.
2. For an ordinary direct self call, prove the remainder is cleanup followed by return of the call result.
3. Require exactly one DictHeap decrement.
4. Trace preceding MIR move aliases from recursive arguments to the decremented Dict register.
5. Retain the replacement Dict, perform the original decrement, move loop parameters, and jump to the loop body.
6. Leave all nonmatching direct calls unchanged.
