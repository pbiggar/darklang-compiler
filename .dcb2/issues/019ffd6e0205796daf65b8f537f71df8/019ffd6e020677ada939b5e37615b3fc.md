# Outline composite-print ARM64 lowering

Reduce fixed ARM64 Code Generation latency by isolating unused composite-print lowering from the hot instruction dispatcher.

## Constraints

- Limit retained changes to ARM64 pass 6 PrintList, PrintSum, and PrintRecord dispatch; retain one cold-path extraction only.
- Use an isolated worktree with a pinned revision, toolchain, host conditions, warm-up policy, and alternating run order.
- Profile composite-print case frequency and JIT cost first; discard the trial if the outlined body is not material.
- For every routine benchmark program, collect 10 paired before/after -vv runs and report raw Code Generation and total-compilation results, medians, absolute deltas, and percentage deltas.
- Collect 10 paired before/after ./run-tests --ai wall-clock runs with raw results, medians, and deltas; require all runs to pass.
- Require identical symbolic ARM64 streams, binaries, benchmark outputs, and instruction counts; run ./run-tests --ai and ./benchmarks/run_benchmarks.sh --verify routine and report the RESULTS.md ratio.
- Retain only a clear improvement beyond a predeclared noise threshold; record discarded alternatives and remove all profiling and instrumentation.

## Trial work

### Trial item 019ffd6e02067866a33cbfe36d5a55c9

Title: Measure composite-print JIT cost

Category: ARM64 code generation profiling

Evidence: Current routine -vv timings put Code Generation at 22.5–66.6 ms and make it the largest pass for most programs; convertInstr embeds large PrintList, PrintSum, and PrintRecord bodies even when absent.

Outcome:

Quantify dispatcher JIT time and composite-print case frequency across scalar and fasta workloads.

### Trial item 019ffd6e020679fd8630c06278136152

Title: Trial one composite-print outline

Category: ARM64 cold-path outlining

Evidence: Existing .dcb2 evidence showed that outlining unused file lowering reduced ARM64 dispatcher JIT time, while composite-print lowering remains unrepresented.

Outcome:

Move the three composite-print cases behind one cold function boundary while preserving dispatch errors and instruction order exactly.
