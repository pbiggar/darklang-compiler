# Skip no-op equality-helper rewriting

Reduce Type Checking time by preserving the original AST when no equality helper calls require materialization.

## Constraints

- Limit scope to `materializeEqHelpersInTopLevels`; retain only the empty-helper fast path that returns the original top levels, while preserving the existing rewrite and helper-generation path when helper types exist.
- Temporarily profile traversal time and allocations on a no-helper benchmark plus a structured-equality control; retain the fast path only if the avoided rewrite is material and remove all profiling and instrumentation afterward.
- Collect 10 comparable before and after nbody `-vv` runs with raw Type Checking and total-compilation timings, medians, absolute deltas, and percentage deltas.
- Because routine benchmark timings drove selection, report before/after Type Checking and total-compilation deltas for every routine benchmark program.
- Collect 10 comparable before and after wall-clock runs of `./run-tests --ai` with raw results, medians, and deltas.
- Require structurally identical transformed ASTs, helper output, diagnostics, and binaries; run `./run-tests --ai` and `./benchmarks/run_benchmarks.sh --verify routine`, reporting every instruction count and the `RESULTS.md` performance ratio; discard neutral, noisy, or regressive results.
