Eligibility analysis is O(program size); evaluation is bounded by fuel, with persistent-map operations adding logarithmic factors. Residual risk is limited to authoritative repository-wide validation, which the worker owns; the canonical suite and routine benchmark were intentionally not run.

## Algorithm

1. Locally optimize functions while retaining their ANF bodies. 2. Accept only Int64/Bool functions whose complete body uses supported non-failing scalar operations and whose calls are exclusively direct self-tail calls. 3. Attempt evaluation only when all call arguments are closed scalar literals. 4. Interpret ANF in evaluation order using wrapping Int64 operations, explicit environments, 100000 fuel, and a 16384 allocation limit. 5. Reuse the evaluator frame for tail recursion; stop without rewriting on exhaustion, unsupported values, effects, allocations, external calls, or unsafe operations. 6. Replace a completed call with its literal result and rerun local propagation/DCE; otherwise retain the runtime call unchanged.
