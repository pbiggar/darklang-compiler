# Trial result

The preserved tail-merge candidate regresses the focused MIR-optimization timing and does not reduce native size for the exact branchTail probe. No established-suite improvement was proven; overall multiplier: 1×.

## Evidence

## Problems

Remove duplicated pure MIR branch tails when a shared continuation measurably improves generated code.

## Solution

The transformation correctly shares the duplicated Add/shift suffix through a typed phi while retaining both incoming control-flow edges. Focused execution output was equal, but the MIR optimization pass median regressed from 0.3 ms to 2.0 ms, exceeding the 1.0 ms threshold in the wrong direction; native binaries were both 288 bytes. Therefore this is not a clear focused win. Residual risk: the registered verifier could not consume the embedded optimization-test source as a standalone workload, so its complete artifact is invalid; an external temporary extraction of the exact probe supplied the comparable measurement and was removed.

## Implementation

- Preserved candidate introduces scalar-only, effect-free MIR branch-tail merging with typed shared-input phis.
- Preserved candidate retains distinct branch-edge labels and rejects effectful/reference-count tails.
- No files were edited, replaced, discarded, or integrated during measurement.

### Algorithm

1. Detect equal-length scalar BinOp tails on both conditional branches.
2. Reject calls, allocations, loads/stores, refcount operations, phis, and non-scalar instructions.
3. Match corresponding tail operations structurally, allowing branch-local SSA inputs to differ.
4. Create typed phis for differing inputs in a shared continuation.
5. Redirect both branch tails to that continuation while retaining distinct predecessor labels.
6. Preserve order and phi-copy locations; leave effectful or unsupported tails unchanged.

### Example

Before: then computes x + 1 then shifts left once; else computes y + 1 then shifts left once. After: thenEdge and elseEdge jump to tail_merge_0, where Phi([(x, thenEdge), (y, elseEdge)]) feeds one Add and one shift. The focused MIR diff proves this shape; both generated executables exit 0 with identical empty stdout.
