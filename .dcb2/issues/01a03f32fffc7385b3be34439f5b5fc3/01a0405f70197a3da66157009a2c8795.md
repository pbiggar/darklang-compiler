## Problems

Specialize hot direct-call functions for a bounded set of scalar literal arguments.

## Solution

The candidate clones functions for small deterministic sets of scalar literal arguments, substitutes those literals into cloned bodies, removes the corresponding parameters, and reroutes matching direct calls while retaining the original function as fallback. Exact float bits distinguish values such as signed zero. Ownership-sensitive managed literals and indirect uses are excluded. The focused measurement is inconclusive: the registered verifier's stage regex accepts only one decimal component, so the exact stage number 2.4.5 was not recognized and correctness comparisons were never reached. Residual risks remain bounded code growth and unverified focused performance.

## Implementation

- Adds bounded scalar-literal clones for internal direct-call-only functions.
- Caps cloning at four variants per function and sixteen per program.
- Preserves recursive tail-call signatures by specializing only unchanged pass-through parameters.
- Retains dynamic-call fallback and rejects function references, closure targets, managed literals, and excessive clone families.
- Adds ANF/MIR/LIR and generated-code coverage and documents the optimization.

### Algorithm

1. Perform existing uniform literal-parameter propagation. 2. Identify internal functions used exclusively through direct calls. 3. For recursive functions, retain only scalar parameters passed unchanged through every self-call. 4. Construct deterministic, bit-exact literal patterns and require multiple variants. 5. Enforce per-function and whole-program clone caps. 6. Clone eligible bodies, substitute literals, and remove specialized parameters. 7. Rewrite matching normal, borrowed, and tail calls without reordering remaining arguments. 8. Preserve the original function and unmatched calls as fallback.

### Example

For two direct calls target(1) and target(2), the candidate may create target$1() and target$2() with 1 and 2 substituted into their ANF bodies, then route each call to its zero-argument clone. A dynamic target(x) call continues to use target(x), demonstrating specialization without removing the unspecialized path.
