# Design brief

## Problem

The compiler’s complete HAMT-backed Dict must be preserved while its language-visible contract is brought into exact parity with the pinned interpreter.

## Goals

- Establish a revision-pinned interpreter contract for every comparison.
- Match public Dict types, callability, type restrictions, results, traversal, equality, and failures.
- Retain native internals while explicitly classifying or removing public extensions and intentional divergences.

## Proposed solution

Using compiler b2e1f3d1e4ce0338d4c4662db9a1326f2e2cb899 and interpreter 04fbe9dcc995c6188757d583e273cbd30a3e2d3d as the evidence baseline, revalidate the earlier report and current parity documents against source and focused same-source observations. Align the compiler’s exposed Dict contract and accepted type combinations with the interpreter while preserving the HAMT, runtime representation, and non-public helpers. Treat related surface and behavioral differences as one coherent parity change, with any retained compiler-only behavior documented as an intentional divergence.

## Success criteria

- Equivalent programs expose the same Dict types, callable surface, signatures, and arities.
- Construction, lookup, duplicate keys, traversal, equality, and language-visible failures match the pinned interpreter.
- Unsupported key, value, and generic combinations are rejected consistently with the interpreter.
- The complete HAMT/runtime implementation remains intact, and excess public aliases or extensions are no longer observable.
- Every comparison records both exact revisions and has current source or focused behavioral evidence.
