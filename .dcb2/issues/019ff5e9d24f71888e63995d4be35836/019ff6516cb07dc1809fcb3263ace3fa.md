# Work plan

ARM64 code generation applies one peephole pass to the combined symbolic program. Each BIC candidate currently rescans its remaining suffix to prove the all-ones mask dies, creating potentially superlinear work while enforcing conservative read, overwrite, end-of-stream, and control-flow semantics.

## Work item 019ff6516cb07913b90485055bfb55e9

Title: Precompute BIC mask lifetimes once

Category: function

Evidence: `src/DarkCompiler/passes/arm64/6_CodeGen.fs:6181-6322` classifies each instruction and linearly scans a supplied suffix; `:6352-6377` invokes that scan independently from both BIC operand-order patterns; `:7084` peephole-optimizes the combined function and runtime-helper stream. `src/Tests/compiler-passes/ARM64CodeGenTests.fs:217-250` covers basic fusion, a live inverted temporary, a live mask, and a later overwrite but not barrier or read/write-precedence equivalence. `src/DarkCompiler/CompilerLibrary.fs:613-629` exposes `-vv` Code Generation timing and `:1540` reports total compilation. The routine profile contains 19 programs, and `benchmarks/RESULTS.md` currently records a 2.74x ratio.

Outcome:

After individual human approval, capture matched baseline measurements and temporarily profile the BIC lifetime helper to confirm repeated suffix scans are material; stop and remove instrumentation if they are not. Add focused regression coverage for both EOR operand orders, end-of-stream death, overwrite-before-read, read/write precedence, and control-flow or label barriers. Implement only one reverse lifetime-summary pass aligned with the original instruction suffixes: end-of-stream means dead, reads and barriers prevent fusion, overwrites prove death, and unrelated instructions inherit the following state. Replace both BIC guards’ suffix scans with summary lookups without changing any emitted symbolic instruction. Remove all profiling code. On the same idle ARM64 host and toolchain, collect 10 alternating comparable before/after fasta `-vv` Code Generation samples and 10 before/after `/usr/bin/time` wall-clock `./run-tests --ai` samples; report raw values, medians, absolute and percentage deltas, and reject the candidate under a predeclared noise rule. Report Code Generation and total-compilation before/after values and deltas for all 19 routine programs. Require byte-identical symbolic ARM64 output and binaries, then pass `./run-tests --ai` and `./benchmarks/run_benchmarks.sh --verify routine`, reporting every routine instruction count and the `RESULTS.md` performance ratio.
