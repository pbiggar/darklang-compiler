# Trial result

## Evidence

## What changed

No changes retained or committed; the typed-lattice SCCP experiment, three MIR snapshot tests, and temporary input were removed.

## How it works

The current optimizer lacks phi constant propagation, and a typed integer/Boolean SCCP prototype correctly propagated constants through executable phi edges while excluding floats and heap-like values. Its three focused cases improved deterministically, but full-suite validation remained CPU-bound for over three minutes with only initial progress, so the new whole-CFG dataflow cost was not commensurate with the retained evidence. The experiment was reverted.

## Algorithm

Prototype only: initialize the entry as executable; iteratively mark executable edges; join scalar phi inputs only from executable predecessors; fold integer/Boolean dependent expressions; rewrite known operands; then let existing CFG pruning remove constant branches and unreachable blocks.
