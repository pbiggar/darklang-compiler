## What changed

Added a typed integer/Boolean SSA lattice, executable-block and executable-edge discovery, constant replacement, phi-edge trimming, and unreachable-block pruning in `3.5_MIR_Optimize.fs`; added focused MIR regression snapshots for constant phis, loop-carried phis, dependent expressions, and unreachable phi inputs.

## How it works

Existing propagation excluded phi destinations and only simplified already-literal branch conditions. The retained SCCP analysis propagates only explicitly typed integer and Boolean values; heap representations, FloatSymbol values, unsupported definitions, and NaN-sensitive float relations become overdefined. The analysis monotonically discovers values and executable edges to a fixed point, then rewrites constants and lets existing folding, DCE, and CFG cleanup finish the transformation. Full rescanning makes worst-case compile-time complexity roughly proportional to dataflow iterations times CFG size; the principal residual risk is compile-time overhead on unusually large MIR graphs. The focused IR reduction is commensurate with the machinery, so the clean candidate was committed. Temporary baseline inputs and worktree were removed.

## Algorithm

1. Collect all SSA-defined registers. 2. Initialize the entry block as executable and values as Unknown. 3. Evaluate executable instructions using the typed Unknown/Constant/Overdefined lattice. 4. Meet phi inputs only when their predecessor edge is executable. 5. Mark one branch edge for a constant Boolean condition, both for overdefined conditions, and defer unknown conditions. 6. Iterate until values, executable blocks, and executable edges stabilize. 7. Replace proven scalar definitions and uses with literals, trim non-executable phi inputs, and remove non-executable blocks. 8. Run the existing constant folding, DCE, and CFG simplification pipeline to fixed point.
