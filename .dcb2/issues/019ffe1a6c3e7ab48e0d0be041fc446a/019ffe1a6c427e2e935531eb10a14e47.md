# Partition ARM64 lowering by instruction family

Reduce the fixed Code Generation cost while preserving the symbolic instruction stream.

## Constraints

- Limit changes to convertInstr dispatch in src/DarkCompiler/passes/arm64/6_CodeGen.fs and retain one family-partition design.
- Collect 10 paired alternating before/after -vv runs for every routine program, reporting raw Code Generation and total timings, medians, and deltas under pinned conditions.
- Require identical symbolic ARM64, binaries, outputs, and instruction counts; run ./run-tests --ai and ./benchmarks/run_benchmarks.sh --verify routine and report the RESULTS.md ratio.
- Discard results within noise or with any total-time regression; remove all profiling instrumentation.
