# Token-bounded current-main retry

- Phase zero is applicability: inspect current main and stop as `no-improvement` if the target disappeared, was already optimized, or lacks a focused deterministic proof.
- Run `./scripts/agent-tool pass-optimization inspect` before broad repository searches.
- Wrap noisy commands with `scripts/concise-command NAME .dcb/tool-artifacts/NAME.log -- COMMAND...`; keep full output in the artifact and return only its summary or actionable failure.
- Stop before 25 shell commands or 100 KB of command output unless a focused proof already shows improvement.
- Use the smallest focused fixture and quick measurement first. Pay for ten-run matrices and repository-wide checks only after a clear signal; the worker owns final canonical verification.
- Keep final structured evidence compact: only changed metrics, regressions, and failing checks.
