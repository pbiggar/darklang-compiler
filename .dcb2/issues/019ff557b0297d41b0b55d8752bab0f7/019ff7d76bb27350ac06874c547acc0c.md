# Emit ARM64 code directly into byte storage

Reduce the current 18.3 ms fasta ARM64-emission median by eliminating machine-code list materialization and reserialization.

## Constraints

- Limit the issue to the ARM64 encoding-to-binary hot path and retain only one direct byte-storage optimization.
- Obtain individual human approval before implementation.
- Collect 10 comparable before and after selected-pass timing runs with raw results, medians, absolute deltas, and percentage deltas; reject neutral or noisy results.
- Report before/after selected-pass and total-compilation deltas for every routine benchmark program.
- Collect 10 comparable before and after ./run-tests --ai wall-clock runs with raw results, medians, and deltas.
- Prove emitted binaries and verbose machine-code output remain correct, then run ./run-tests --ai and ./benchmarks/run_benchmarks.sh --verify routine; report instruction counts and the RESULTS.md performance ratio.
- Remove all exploratory profiling and instrumentation from retained code.
