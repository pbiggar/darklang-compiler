## Algorithm

1. Identify eligible Int64-returning functions with one direct self-call wrapped by final Int64 multiplication.
2. Require a parameter/literal Int64 factor and only pure first-order bindings.
3. Reject Float, managed/effectful, indirect, multiple-call, and unsupported-control-flow forms.
4. Create a helper with accumulator initialized to one.
5. Multiply the accumulator before the recursive helper call.
6. Return accumulator times each base result, preserving modulo-2^64 overflow.
7. Let existing tail-call lowering form the loop back-edge.
