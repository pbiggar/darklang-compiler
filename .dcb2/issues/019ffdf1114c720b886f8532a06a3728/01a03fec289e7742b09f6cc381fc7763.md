## How it works

The baseline performs 400,400 successful vector reads and materializes a 16-byte Option for each, then loads its tag and payload and releases the wrapper. Retaining the immediate match was measurably slower. A benchmark-name compiler special case was rejected, while a general compiler rewrite would be more invasive and must account for default-expression evaluation semantics. The retained explicit API is the smallest reusable solution: it preserves O(log n) lookup, bounds fallback, and payload bits while bypassing Option construction. Residual risk is that getAtOrDefault evaluates its default argument eagerly like any ordinary function call, so future callers should avoid expensive defaults; the benchmark uses the literal 0.0.

## Algorithm

1. If index is negative, return the supplied default. 2. Read the skew-list length; if index is at or beyond it, return the default. 3. Otherwise invoke the existing digit traversal, subtracting complete-tree weights until locating the containing tree. 4. Traverse that complete tree by child weights to the requested element. 5. Return the stored payload directly, preserving its exact Float bits and never constructing an Option.
