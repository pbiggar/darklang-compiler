## How it works

Current optimized ANF and post-allocation LIR still expand edigits getAt/setAt operations into SkewList traversal, immutable path copies, Option allocations, and releases. The recovered Blob-backed feasibility fixture preserved one Int64 per decimal digit and the exact arithmetic, while replacing that work with direct 8-byte loads and stores. It repeatedly showed a decisive improvement and preserved checksum 2162278. It was rejected because existing ownership machinery tracks reference-count obligations and capture-free closure escape, but provides no interprocedural proof that e and term are uniquely owned, monomorphic Int64, non-escaping, and visible only to understood calls. Retaining raw mutation without that proof would be incorrect; recognizing this particular call graph would be benchmark-specific. A safe implementation therefore requires a broader representation-selection analysis with conservative fallback. The main residual risk is accidental semantic breakage if future work treats manual linear use as equivalent to compiler-enforced uniqueness.

## Algorithm

1. Pin the clean baseline and recover the prior trial checkpoint.
2. Compile current digit-at-a-time edigits with ANF and LIR dumps.
3. Confirm divideByN and addWithCarry still contain SkewList traversal, path-copy allocation, Option allocation, and ownership releases.
4. Recompile the temporary feasibility fixture using two reference-counted contiguous buffers with one 8-byte Int64 slot per decimal digit.
5. Use direct RawGet and RawWriteWord operations while preserving carry direction, radix 10, iteration counts, and checksum calculation.
6. Compare quick and canonical outputs, Cachegrind metrics, staged IR operation counts, emitted binary size, disassembly size, selected-pass timings, and leak behavior.
7. Apply the ownership gate: reject because uniqueness and non-escape are manually true for this fixture but not statically established by the compiler.
8. Retain only the measured rejection documentation; all Lists continue through ordinary persistent lowering.
