## Important changes

- **Removed the unused runtime record-descriptor word and restored fields to offset zero** — **Reason:** compact record allocation removes the avoidable cost introduced by nominal-record lowering while retaining compile-time nominal semantics.
- **Updated record refcount metadata and its safeguard tests for compact payload sizes and offsets** — **Reason:** release planning must describe the physical layout actually allocated.
- **Updated ARM64/x64 native record-return paths and code-generation fixtures for the compact layout** — **Reason:** those paths previously encoded the shifted descriptor slot.
- **The requested `RecordGet` projection-reuse follow-up is not included** — **Reason:** the attempted reuse made nbody fail ARM64 register allocation (`FVirtual 91 not found`), so that source change and its invalid stale-binary measurement were discarded.
