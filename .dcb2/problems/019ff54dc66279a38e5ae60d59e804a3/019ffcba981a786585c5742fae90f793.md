# Reduce compiler pass compile time

Find measurable compile-time improvements in one compiler pass or hot path at a time. Choose targets from current `-vv` timings or profiling, and vary the passes explored.

Each trial must:

- compare repeated before-and-after pass and total compile timings;
- run the full test suite and relevant routine benchmarks;
- preserve generated-code behavior and performance;
- remove exploratory instrumentation from retained code.

Keep only a clear improvement outside measurement noise. Discard neutral, noisy, or regressive experiments.
