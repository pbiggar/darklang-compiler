# Classic Optimizations Context

## Initial Context And Prompt

The compiler implements some optimizations that are well-known and implemented in many compilers. However, there are many more that it could and should implement. Find optimizations by listing classic optimizations and comparing against the optimizations implemented in the compiler. Each should have specific test files added that test the implementation, by verifying the before- and after-optimization versions of the relevant IR. If the existing benchmarks do not improve, new benchmarks should be found.
